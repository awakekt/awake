- `SceneCapability` is now `SceneFeature`, `BlueprintCapability` is `BlueprintFeature`, `loadCapabilityContent` is `loadFeatureContent`, and the `verifyCapabilityLayering` Gradle task is `verifyFeatureLayering`, to match `GameFeature` and `ClientNetFeature`. The old names stay for one release as deprecated aliases with a replacement, so a game built against an earlier release still links and recompiling offers the new name. Parameter names such as `capabilities`, and the `capabilityClass` key of a manifest's `plugins` entry, are unchanged (#1527).
