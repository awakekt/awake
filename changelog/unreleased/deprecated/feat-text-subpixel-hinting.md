- **`PixelGlyph.anchorX` is deprecated.** The subpixel variants replace it: a renderer picks the variant for the pen's fraction of a pixel (`PixelGlyph.subpixelSteps`, `PixelGlyphs.glyph` with a step), and each variant already has its main stem on the pixel grid. `anchorX` now always returns 0, which keeps a renderer that still draws `round(penX + anchorX) + left` working with the whole-pixel variant, and it will be removed in a later minor (#1005).
