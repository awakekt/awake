- **Rounded UI borders compile on WebGPU (`UiRoundedQuadShader`, `FxaaShader`, `AslValidation`).** `UiRoundedQuadShader` now takes `fwidth(distance)` once in uniform control flow ahead of `if (strokeWidth > 0.0)`, `FxaaShader` samples its edge branch with `textureSampleLevel(..., 0.0)`, and `AslValidation` rejects `dpdx`, `dpdy`, `fwidth`, and `textureSample` inside any branch or loop at shader-definition time so WebGPU's uniformity check cannot be broken silently (#1559).
