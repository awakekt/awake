- A compiled frame's draws are no longer sorted a second time by the backend that records them: `GpuPassInput.drawsInRecordingOrder`, set by the scene compiler, lets the WebGPU and Vulkan executors record the lists as they are, a pass input built by hand still being sorted. Depth passes reuse shared keys (`DepthRenderKey.of`) instead of making one per draw per cascade, and WebGPU's stable draw slots no longer make an iterator per mesh each batch.
