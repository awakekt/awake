- **A client dropped for a full outbound queue is now logged and reported to the host as such.** `GameTransport` closed a slow session on outbound overflow without a trace, so the host saw an ordinary disconnect. It now logs one warning with the session id and the outbox capacity, and `TransportSession.closeReason` (`PeerClosed`, `OutboundOverflow` or `ServerClosed`, `null` by default for other implementations) is set before `incoming()` closes.
