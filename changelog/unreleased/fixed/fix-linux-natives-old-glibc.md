- **The Linux shader compiler loads on current LTS distributions again.** Since 0.45.0, `libawake_naga.so` was built on `ubuntu-latest`, whose glibc 2.43 it then required (`acosf`, `asinf`, `acoshf`, `sinhf`, `coshf`), so on Ubuntu 24.04 (glibc 2.39), Debian 12 and the like `NagaShaderCompiler` failed to load and nothing drew. The Linux native libraries (naga, Vulkan bindings, window) are now built on `ubuntu-22.04`, and `tools/check_linux_glibc.sh` fails the release when one needs a glibc newer than 2.35.
