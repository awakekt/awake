- On Vulkan, a still UI that draws an offscreen layer every frame no longer re-uploads its UI meshes every frame. Each render target now stages its UI runs into its own meshes. A destroyed target's meshes are freed only once the fence of every frame in flight has been waited on since. In the test, a layer and an overlay went from 1,184 bytes uploaded on every frame to 0 once both frames in flight held their meshes (#1545).
