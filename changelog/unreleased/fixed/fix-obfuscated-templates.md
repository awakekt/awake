- **A shrunk release of an app on `awake:project` builds again.** Since content bundle encryption (#1153), `awake:project` uses cryptography-kotlin, whose JDK provider refers to BouncyCastle for when an app ships it. ProGuard stopped the desktop release on those 39 references, and R8 would stop the Android one. `awake:project` and `awake:plugin-archive` now ship consumer keep rules that ignore the optional BouncyCastle references and keep the ServiceLoader names of cryptography-kotlin's providers, without which an obfuscated release finds no provider when it decrypts a bundle or checks a plugin signature.
