- **A glTF model's images no longer stay decoded on the heap after they are uploaded.** `GltfAssetResolver` kept every model image as decoded pixels, four bytes a pixel, for as long as it kept the model, so a streamed world's textures filled an Android heap. Outside a browser it now keeps the image file's bytes: the decoded pixels go once the first material is made, and a material made again for the same name decodes its images again on the calling thread. `asReleasingGpuImageSource` is the image source that does it, and `decodeImageBlocking` with `canDecodeImageBlocking` the decode it uses. A browser keeps its `ImageBitmap` as before, and an image a custom `setImageDecoder` supplies is untouched (#1619).
