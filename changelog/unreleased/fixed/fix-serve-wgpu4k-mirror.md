- **The WebGPU backend keeps building after Maven Central drops its wgpu4k snapshots.** Central removes a snapshot after 90 days, and the wgpu4k builds Core pins date from 2026-07-16. A byte-for-byte copy of them is served from the Maven fallback, `https://awakekt.github.io/awake/`, and Core resolves `io.ygdrasil` there too. A project that builds the WebGPU backend from Central adds the same repository, limited to that group: `maven("https://awakekt.github.io/awake/") { content { includeGroup("io.ygdrasil") } }`.
