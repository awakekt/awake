- **Shared form recipes complete button keyboard activation, disabled-input blocking, and submit forwarding.** `ShadcnButton` (along with `ShadcnButtonGroup`, `ShadcnPagination`, `ShadcnToggle`, and `ShadcnToggleGroup`) now publishes `SemanticsRole.Button` and `SemanticsProperties.Disabled`, joins the focus ring when enabled, activates once per unmodified `Enter` or `Space` key-down, and excludes disabled buttons from focus and activation. `BasicTextField` adds a binary-compatible `enabled: Boolean = true` parameter forwarded by `ShadcnInput`, `ShadcnInputGroup`, and `ShadcnTextarea` so disabled text fields drop and refuse focus, publish `SemanticsProperties.Disabled`, block pointer selection, typing, paste, IME composition/commit, and edit commands while preserving the caller's `TextFieldState`, and `ShadcnInput` and `ShadcnInputGroup` add binary-compatible `onSubmit` parameters forwarding single-line `Enter` submission (#1304).
