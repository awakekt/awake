- **Project-content tasks run after `generateAssetsLock` when scheduled together.** Selecting `generateProjectIndex` (or `checkProjectContent` / `generateContentBundles`) alongside `generateAssetsLock` in one Gradle invocation failed Gradle's implicit-dependency validation on `assets.lock.json` because the tasks shared the file without an ordering edge. `validateProject`, `verifyAssetsLock`, `generateProjectIndex`, `generatePublicContentBundles` and `generateContentBundles` now declare `mustRunAfter(generateAssetsLock)`, and `generateProjectIndex` and `validateProject` follow `projectContent.assetsLockFile` (and `manifestFile`) instead of hardcoding `assets.lock.json`, so combined runs write the lock before indexing, bundling or verifying it in either requested task order while standalone `generateProjectIndex` and `check` still leave `assets.lock.json` untouched (#1312).
