- On WebGPU, a still UI that draws an offscreen layer every frame no longer re-uploads its UI meshes every frame. Each render target now stages its UI runs into its own meshes, freed when the target is destroyed, instead of sharing the overlay's, where each pass overwrote the other's. In the test, a layer and an overlay went from 1,120 bytes uploaded on every frame to 0 after the first (#1545).
