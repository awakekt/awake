- **`IndexedAssetSource` takes its key provider as a trailing lambda again.** 0.61.0 added `limits` after `keys` in the constructor and both `open` functions, so a 0.60.0 call that passed `keys` as a trailing lambda stopped compiling: the lambda met a `BundleMemoryLimits`. Each now has an overload that ends with `keys`, required and nullable, with the same JVM signature as 0.60.0's; every 0.61.0 call still resolves as before. (#1832)
