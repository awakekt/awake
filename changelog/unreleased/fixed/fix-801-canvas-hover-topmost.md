- **A canvas element is hovered under a later sibling's anchor padding.** `SceneCanvas` wraps each element in a padded box to place it, and a non-button element only watches the pointer. So when no sibling took the point, hit testing kept the topmost box under it, often a later sibling's empty padding, and the element actually under the pointer was never hovered. Now a node that watches the point outranks one that only holds it, as in Compose, where a box with no pointer input isn't hit at all. A node that takes the point, such as a Button, still wins over both.
