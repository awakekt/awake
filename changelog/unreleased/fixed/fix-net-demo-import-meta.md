- **The network demo's browser client loads again under Kotlin 2.4.20.** Ktor 3.5.1 brought kotlinx-io 0.9.0, whose wasm Node helper reads a bare `import.meta` that Kotlin 2.4.20's webpack no longer rewrites, so `samples/net-demo`'s page and its `wasmJsBrowserTest` failed with "Cannot use 'import.meta' outside a module". The repository's Ktor moves to 3.5.2, which brings kotlinx-io 0.9.1, and CI now runs net-demo's browser tests (#915).
