- **A skinned glTF draws every primitive of its meshes, and its mesh nodes with no skin.** A skinned mesh with several primitives, one per material as exporters write it, drew only its first; now each is a `gltf-primitive:<path>#<index>` part with its own material in `materialSlots(path)`. A mesh node with no skin, such as a prop parented to a hand joint, was never drawn; now it is a part too, bound to the joint above it so it follows that joint as the clip plays, or drawn in place as static geometry when no joint is above it. The parts a model already had keep their numbers, so a saved scene still names the same ones. Parts that share a pose now each draw in their own material's colour; they all took the last part's. `GltfParser.parseSkinned` reads every primitive into `LoadedSkinnedScene.primitives` and lists the unskinned mesh nodes in `rigidNodes`, and `bindRigidNode` and `restTransform` place one.
