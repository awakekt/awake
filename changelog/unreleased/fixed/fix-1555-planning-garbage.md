- **Planning a still 3D scene no longer makes garbage per renderer.** Instance folding keeps its groups, model lists and instanced requests from frame to frame instead of building a key, a map entry, a list and a copied request for each one, and the planner no longer copies its draw lists into temporary arrays. On the JVM a still frame of 3,000 renderers on 190 meshes went from 280 KB to 29.5 KB of garbage, the same at 1,000 renderers, and the same while the camera moves. An instanced group of fading copies also keeps its fade, which copying the request used to reset (#1555).
