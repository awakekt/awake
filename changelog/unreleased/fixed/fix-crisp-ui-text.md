- **Small UI text is no longer soft on Vulkan.** The font atlas was uploaded with a mip chain, and at 11 to 22 pixels the sampler's automatic level of detail read mip 1 or 2 of a distance field, where averaging distances erodes thin stems. "Mesh Terrain Texture" at 11px had 13 solid pixels (at least 200 of 255) and now has 194. `ensureFontAtlas` samples the base level only (`TextureFiltering.BaseLevelLinear`), and the WebGPU font sampler no longer asks for a linear mip blend, though WebGPU only ever uploaded one level. The Vulkan baselines that draw text from an atlas are re-recorded.
