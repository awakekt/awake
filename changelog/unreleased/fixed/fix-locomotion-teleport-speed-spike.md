- **A teleport no longer reads as running.** `locomotion_animation` measures ground speed from the entity's world position, so a single frame's jump — a character-controller reconcile, a respawn, a networked entity's leash home — used to spike the smoothed speed and switch the clip to a run (and, under speed-matched playback, race it) for the fraction of a second the smoothing took to bleed the spike off. One frame's move faster than any stride is now treated as a teleport and left out of that speed, so a jump in position keeps whatever clip was playing instead of flapping into a run (#1226).
