- **Cancelling a glTF, collision mesh or pipeline load stops it instead of failing it.** `GltfParser.load`/`loadExternalResources`, `GltfAssetResolver`'s bundled reads and material preload, and a project's collision-mesh reads caught the coroutine's cancellation in `runCatching`; they now use `suspendRunCatching`. `withPipelineLoadContext` wrapped a cancellation in an `IllegalStateException` naming the pipeline, so a cancelled engine start reported a pipeline that failed to build; it now lets the cancellation through. A content feature whose build is cancelled part way releases its pipeline and uploads, as a failed one already did (#1321).
