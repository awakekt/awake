- A scene's compile no longer allocates for each renderer's vertex animation (#1621). Instance folding compared draws' animation vectors with `==`, and on Kotlin/Wasm `Vec3f`'s data-class `equals` boxes each `Float` it compares. A scene gives each renderer its own vector, so the compile of 3,000 renderers cost 172 B a renderer in the browser (130 with transforms built), against 15 (17) for copies sharing one vector. The vectors are now compared component by component, and a browser test in the Web CI job holds the scene's compile at 48 B a renderer.
