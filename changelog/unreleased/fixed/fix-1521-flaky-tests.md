- **Interpolating physics bodies no longer allocates, and three flaky tests are deterministic.** `Quat.nlerp(a, b, t, target)` blends into a quaternion you own, and `PhysicsSystem.interpolate` uses it, so a frame allocates no `Quat` per body (it was 32 bytes per body, hidden only while the JIT's escape analysis removed it). The physics and read-tracking allocation probes now run with escape analysis off and assert on the minimum of several windows, and the wasm bundle-verification benchmark reports its time and asserts only on the bytes verified (#1521).
