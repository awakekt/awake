- **An entity attached to a joint with `SocketAttachmentComponent` lands on that joint, not at the character's feet.** `SocketAttachmentSystem` read the joint's skinning matrix, which is close to identity near the bind pose, as if it were the joint's transform. It now multiplies the bind matrix back in through the target's skin, so the entity follows the joint's world transform. The offset applies in the joint's own space, so a grip turns with the hand. A `jointName` resolves to the joint's index in the skin, the palette's order, rather than the skeleton's bone index. The system composes the target's world transform from its current position, rotation and scale, so the attachment no longer trails a moving character by a frame. An attached entity that has a parent gets the local transform that puts it on the joint. `Skin.jointTransform(palette, joint)` gives a joint's own transform under a palette, for code outside a scene.
