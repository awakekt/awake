- A frame's draws no longer allocate garbage asking their vertex format whether it is skinned, comparing or hashing it, or sorting by batch key or transparent order. `VertexFormat` keeps its hash and `isSkinned` from construction and compares attributes by index; the sorts compare primitive keys instead of boxing them. Measured with escape analysis off, as the web build runs: a 3,000-draw moving frame drops from about 5.0 MB to 3.2 MB (#1555).
