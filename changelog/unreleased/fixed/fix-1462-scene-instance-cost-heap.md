- **The scene instance cost test no longer fails at random with a negative reload heap (#1462).** `SceneInstanceCostTest` measured the heap its live copies retain against a reading taken before making them, straight after the timing phase, so memory the timing phase's closed copies hadn't released yet could count in the baseline and push the reload delta below zero. It now takes the live reading, closes the copies and drops them, and measures against the heap after they are gone. The runtime itself is unchanged.
