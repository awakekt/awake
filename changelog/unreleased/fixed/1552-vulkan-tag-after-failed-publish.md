- **A Vulkan release whose publish failed can be recovered from the Vulkan tag workflow.** When a `vulkan-v*` tag never reached Maven Central, the release's commit kept carrying it and the tag scripts stopped at "already carries", so the next version had to be tagged by hand. The workflow's new `replace_unpublished` input pushes the next version on the same commit; the scripts refuse when the carried tag is on Central or Central cannot say.
