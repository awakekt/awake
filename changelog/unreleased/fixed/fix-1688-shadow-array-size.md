- The shadow depth array holds only the layers a scene draws. Both backends used to allocate all 28 layers (4 cascades plus 4 point lights' 6 faces) of 2048-texel 32-bit depth, 448 MiB committed on Vulkan, whatever the scene drew. The array now starts at the 3 default cascades, 48 MiB. It grows once when a shadowed point light first appears: 160 MiB for one point light, and 448 MiB only when all four cast. It never shrinks mid-scene. On Vulkan the old image is freed after the device goes idle. On WebGPU it is closed at once and the cached shadow bind groups are rebuilt over the new texture. The pictures are unchanged. `Renderer.shadowMapBytes` reports the bytes allocated now (#1688).
