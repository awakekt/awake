- On the web, a moving camera no longer creates GPU buffers every frame. Each re-recorded render bundle cell created a fresh indirect-arguments buffer, and every buffer is a new wgpu4k `Buffer`, whose web wrapper builds a logger by capturing and parsing a JavaScript stack trace: thousands a second, at kilobytes of garbage each, on a moving camera over a large scene. Released cells' argument buffers are now pooled by size and reused, so a warm moving camera creates none: 1,884 buffers over 200 frames before, 0 now, at 3,000 shadowed draws (#1555).
