- **A glTF material with no base colour image resolves as `gltf-material:`, so its mesh spawns (#1409).** `GltfAssetResolver` registered a static primitive's material only when it had a base colour image, so a `mesh_renderer` naming the material of a `.glb` with only `pbrMetallicRoughness` factors failed with "No scene material named 'gltf-material:…'". Such a material now resolves to the plain lit material its untextured geometry draws with, and keeps its factors: the base colour in the geometry's vertex colours, and metallic, roughness, emissive and alpha mode as the entity's material defaults. Textured materials resolve as before, and the editor still places an untextured model with `lit-shadow`.
