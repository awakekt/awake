- **Wrapped text breaks a line where a browser does.** A line that wrapping made was kept on the line when it overran the box by up to half a pixel, so a 12 px paragraph in a 110 px box took 3 lines where Chromium takes 4. A wrapped line now fits only when it is no wider than the box, compared in a browser's 1/64 px units, and a box sized to wrapped text is rounded up to the next whole pixel so the text still fits the box it was measured to; a single unwrapped line is sized as before.
