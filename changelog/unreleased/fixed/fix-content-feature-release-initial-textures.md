- **An attached content feature's pixels no longer stay on the heap after they are uploaded.** The Vulkan and WebGPU backends kept each uploaded `ContentFeature` alive through the upload's per-frame step, and with it every `TextureAsset` the feature was built from. For a paged terrain that is a zero-filled array for each page image at the terrain's full capacity, about 25 MB in a streamed world, which only shapes the texture when it is created. The upload now keeps the feature's texture updates and nothing else of it (#1619).
