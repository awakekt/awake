- **Every keyboard key is polled on desktop.** `DefaultGlfwGameplayKeys` previously only mapped W/A/S/D, arrow keys, space, escape, and F1..F12, so letter keys (such as `I` for inventory or `N` for navigation) and digit keys were not forwarded to Awake `Input` on desktop. It now maps all letters A..Z, digits 0..9, F1..F12, Tab, Enter (including keypad Enter), Backspace, Delete, Home/End, PageUp/PageDown, and modifier keys without allocating on the frame loop.
