- **A browser canvas shows the pointer shape the UI asks for.** The web host never read a frame's cursor request, so a text field, a link or a resize handle left the browser's arrow in place. `launchWebGpuGame` (both overloads) and `runBrowserCanvas` take an optional `cursor` lambda, as the desktop hosts do, and set the canvas's CSS `cursor` from it when it changes: `default`, `ew-resize`, `ns-resize`, `nwse-resize`, `nesw-resize`, `pointer` and `text`. Pass `cursor = { runtime.cursor }`; without it the canvas keeps the page's own cursor. The UI and Compose showcases pass theirs.
