- **A click reaches the topmost element under the pointer that handles it, instead of stopping at a box that handles nothing.** Hit testing used to stop at the first sibling whose box held the point, whether or not anything in it took the event. A scene UI of nested canvas elements anchored `TopLeft` with offsets could therefore be clicked only on its last-drawn button, because each element sits in a box inset by its offset and that box reaches back over every earlier sibling. A child whose subtree does nothing with a pointer where it lands, such as a layout's padding box or a decorative panel, is now passed over and the walk goes on to the sibling beneath it, as in Compose. A pointer link counts by its own box, so `padding(..).clickable { }` leaves its padding to whatever is behind it. A node that scrolls, takes focus or asks for a cursor still takes the point, an overlay still blocks what it covers, and a point over nothing but plain boxes finds the same nodes as before.
