- Animations advance once a frame, however many times the frame composes them (#1764). `rememberLoopingPhase`, `animateFloat`, `animateTrailing`, `ShadcnToaster`, `ShadcnNumberStepper`, the canvas stepper's repeat and the canvas state transition added the frame's delta on every composition pass. A frame that composes twice, because placement wrote state composition read, ran them twice as fast; and a host verifying its skipped compositions reported a stale skip for one inside `BoxWithConstraints`, whose content its own check composed a second time. They now advance through the new `FrameStep`, which hands each frame's delta out once.
