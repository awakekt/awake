- **A character's sweep allocates a sixth of what it did on desktop and Android.** `JoltPhysicsWorld.shapeCast` built a new Jolt shape, start matrix, settings, collector and four default filters on every call: about a dozen JNI objects, each registered with a `Cleaner`. A character controller sweeps about twice a tick, so a crowd of characters made garbage in proportion to its size. The world now reuses one set of these and keeps the Jolt shapes of the capsules and spheres it sweeps. A sweep allocates 268 bytes instead of 1,612, or 556 instead of 2,921 when it starts inside the character's own body. `MeshColliderSystem` no longer creates a `KClass` for every collider on every tick.
