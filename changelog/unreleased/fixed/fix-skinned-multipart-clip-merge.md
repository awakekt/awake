- **Multi-part skinned models spawned over async streams merge clips across sibling parts regardless of arrival order.** `startSkinnedAnimations` skipped any parent entity that already held a `SkinnedPose`, so when a small 1-clip accessory or 0-clip armour file finished downloading before the larger multi-clip body glTF under the same parent, the body's animation library was discarded and the character could never play locomotion or action clips. Later-resolving parts now start an `Animator` if the earlier part had no clips, or retarget and merge missing clips into the parent's `AnimationPlayer` via `addClips`.
