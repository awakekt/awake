- A still UI with more than 256 draw spans, such as a vector-drawn HUD, no longer re-stages and re-uploads the spans past 256 on every frame. The retained UI run cache now keeps every span the frame being drawn uses, and evicts only spans that frame has not used, so a still frame uploads 0 bytes. A hit is a hash lookup, not a linear scan of the cache. In a vector HUD fixture of 282 runs, each still frame went from 26 runs and 251,804 bytes re-uploaded, plus 243 KB of staging garbage, to 0 runs, 0 bytes and 36 KB (#1545).
