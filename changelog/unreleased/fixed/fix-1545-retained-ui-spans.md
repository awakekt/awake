- A still UI with more than 256 draw spans, such as a vector-drawn HUD, no longer re-stages and re-uploads the spans past 256 on every frame. The retained UI run cache keeps every span the frame being drawn uses and drops unused spans, down to its capacity, once per frame. Past its hard bound it keeps the spans it holds and does not store the excess, so only the excess re-stages. Spans are found by hash, collisions included, and a lookup allocates nothing. In a vector HUD fixture of 632 spans, each still frame went from 374 runs, 54,340 triangles and 4,031,624 bytes re-uploaded to none (#1545).
