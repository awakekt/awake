- **A Load Scene naming a scene the project doesn't have warns as the project loads.** A blueprint's Load Scene whose `scene` path names no file of the project was only found out when the node ran and the switch failed. Each such node now logs one warning on the `blueprint` log as the project loads, naming the graph, the node and the path, and the project still plays. A `scene` wired from another node is only known when it runs, so it isn't checked.
