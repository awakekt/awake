- **Closing a project takes its tables out of a shared `Strings`.** When a game passed its own `Strings` to `loadProject`, `LoadedProject.close()` now removes the `strings/` tables that load added and leaves the game's own, so loading a project again into the same instance, as a `projectRoute` does on each entry, no longer keeps the earlier copies. The removal needs no suspend call: it is done when `close()` returns, or right after a locale switch already in flight. Closing twice is still harmless, and a project loaded without a shared `Strings` closes as before (#1141).
