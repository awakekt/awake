- **A spawn that fails leaves the world as it found it (#1410).** `spawn` (and `SceneHostServices.spawn` through it) made the node's entities before resolving their renderers, so a material or mesh that couldn't resolve left the root, its `Name` and its children in the world with no `SpawnedNode` to despawn them. A failed spawn now destroys every entity it made and releases what its renderers already held before the exception reaches the caller, which still gets it. The same holds for a node that fails as it is instantiated, such as a component binding that throws or a node link that names no node.
