- Shadow cost per quality preset: `Renderer.shadowBudget` (`ShadowBudget(cascades, mapSize)`, default 3 cascades of 2048 texels) sets how many cascades a frame plans for a directional light's shadow, each one a depth pass over its casters. `RenderQualitySettings` applies `RenderQualityPolicy.shadowBudget`: `ShadowBudget.Reduced` (2 cascades of 1024) for `RenderQuality.Performance`, and under `RenderQuality.Auto` on a Mobile or Software device; High, Balanced and a desktop under Auto keep 3 cascades. So a phone under Auto, and any app on Performance, now plans 2 cascades instead of 3. Set `RenderQualitySettings.shadowBudgetOverride = ShadowBudget.Default` to keep 3. The map size is carried but not yet applied: both backends still allocate 2048-texel maps (#1688).
