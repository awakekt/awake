- **A played scene's navigation grid is baked once, as the project loads (#1435).** `loadProject` and a scene switch bake the `navigation` component's grid into the scene's content, and every `PathRequestSystem` and perception check planned from that content routes over the same immutable grid, instead of each `sceneSystems` call baking its own from the document. A host that plans a scene with `sceneSystemsFor` and no loaded content still gets a grid baked from the document, and a malformed grid still fails when the scene is planned.
