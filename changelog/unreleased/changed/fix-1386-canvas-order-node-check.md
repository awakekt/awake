- **A scene canvas checks each node above its elements once a frame, not once for each element below it (#1386).** `CanvasItemOrder` keeps its last sort while nothing that decides the order changed. To know that, it walked the whole path above every element each frame, so a window's root was checked once for every element in the window. It now records each node on those paths once, with where its `Transform` is stored and its parent, and checks each once: about 4,000 checks a frame instead of 16,000 for a canvas of 4,000 elements at an average depth of 4. A reparent, a despawn or a new node is still seen on the frame it happens.
