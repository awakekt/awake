- With `ComposeHost.retainUnchangedDraw` on, a subtree that moved as a whole now replays its last primitives unchanged inside a `TranslatePush` and `TranslatePop`, which the UI staging applies as it builds vertices, instead of copying each primitive translated. 200 moving nameplates allocate 6,138 B a frame instead of 138,402 B, and still stage bit-identically to a fresh paint. A frame's primitive list may therefore hold translate ranges: code that reads positions from `FrameOutput.primitives` or `SceneAppLifecycleRuntime.uiPrimitives`, rather than drawing them, reads `flattened()` (#1512).
