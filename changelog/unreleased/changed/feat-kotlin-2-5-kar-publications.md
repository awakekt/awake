- **Kotlin `2.5.0-RC` and `KOTLIN_ARCHIVE` (`.kar.xz`) publications.** Upgraded Kotlin across the build, templates, and standalone tools from `2.4.20` to `2.5.0-RC` and enabled `kotlin.publicationFormat=KOTLIN_ARCHIVE`, packing KMP metadata and KLIB targets (`iosArm64`, `iosSimulatorArm64`, `wasmJs`) into a single XZ-compressed archive per module. Combined with omitting redundant `-android` AARs on pure-KMP modules, this cuts Maven Central release file counts by ~58% (~14,620 → ~6,120 files per Core release). Consuming builds must use Kotlin 2.5+.
