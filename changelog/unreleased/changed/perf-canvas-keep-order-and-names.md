- **A large scene canvas no longer re-sorts every element and re-indexes every named node each frame.** `SceneCanvas` keeps its hierarchy order from frame to frame and sorts again only when an element, a node above one, or where the world stores one of their `Transform`s changes; and it keeps the index of nodes by `Name` that followers, Views and binds look their node up in, building it again only when a lookup finds it out of date, at most once a frame. A HUD of 3,460 elements, mostly in closed windows, over 15,000 named nodes went from 13.4 ms to 1.8 ms a frame on a desktop JVM. A name several nodes share now resolves to the one the index found first for as long as that node keeps the name.
