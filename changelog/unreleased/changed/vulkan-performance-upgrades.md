- **Vulkan hot-path JNI recording, real Vulkan 1.2/1.3 `pNext` feature enabling, direct-present passes, staging reuse, and deferred resource teardown.** Added zero-reflection primitive JNI command/sync/present entry points (`VulkanCommands`, preserving the Android Swappy present hook via `awake::presentWithHook`) and scalar vertex-buffer/int-array writes (`VulkanBuffers.vkCmdBindVertexBuffer`, `writeMappedMemoryInts`); enabled selective Vulkan 1.0 device features (disabling `robustBufferAccess` and unused features), real Vulkan 1.2/1.3 `pNext` feature negotiation via `vkGetInstanceProcAddr`, and persistable `VkPipelineCache` import/export (`GraphicsDevice.initialPipelineCacheData` / `exportPipelineCacheData`); added Vulkan 1.1 dedicated image memory allocation (`vkAllocateDedicatedImageMemory`), ReBAR/UMA `DEVICE_LOCAL | HOST_VISIBLE` placement for UBOs and dynamic buffers with `OUT_OF_DEVICE_MEMORY` fallback, and `HOST_CACHED` pixel readback staging; eliminated `presentTransitionRenderPass` and empty UI render passes with a render-pass-compatible direct-present scene pass and `COLOR_ATTACHMENT_OPTIMAL -> PRESENT_SRC_KHR` barrier, hoisted shadow-cascade barriers out of the cascade loop, omitted fragment stages on opaque depth-only pipelines, pooled UI texture descriptors and cached image-pass descriptors, added a reusable persistently mapped staging buffer with single-submit `Mesh` vertex+index uploads, and retired `Mesh`/`Material`/`VulkanDynamicMesh` resources via `DeferredResourceReaper` to eliminate mid-frame `vkDeviceWaitIdle` stalls.
