- **A scene canvas whose elements hold still allocates nothing to order them.** `SceneCanvas` asked its kept order for the frame's items every frame, and the order built a new list and a new `CanvasItem` per element each time, even when the sort was reused: 4,576 B a frame for 126 elements, and about 77 KB a frame in a populated scene a consumer measured, the largest Core share of its canvas garbage. A frame whose items are the last frame's, the same element, parent and scaler at each position, now gets the last frame's list back; a frame that changes gets a new list that reuses the items that held. A list handed out is never changed afterwards.
