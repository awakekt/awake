- **`World.get` checks liveness through the store it reads (#1428).** Every `get`, by reified type, class or `ComponentType` handle, checked `EntityArena.isAlive` and then looked the entity's id up in the component store. A store now matches the whole handle, id and generation, so a hit already proves the entity alive and the separate check is gone; `PhysicsSystem`'s per-body read-back and interpolation pay one array read less per body. A stale handle whose id was recycled finds nothing, including an entry left in a raw `World.store` for a destroyed entity, which used to answer for the entity that reused its id.
