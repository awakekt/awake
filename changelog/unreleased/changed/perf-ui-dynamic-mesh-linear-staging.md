- **UI dynamic meshes upload through one-copy linear-memory staging on the web.** The WebGPU backend's `ui.DynamicMesh` staged its vertex and index data with `ArrayBuffer.setFloats`/`setInts`, which on the web crossed into JS once per value; a busy UI frame spent most of its `DynamicMesh.update` time there. It now takes the same `fastArrayBufferOf` + `writeBufferData` path textures, meshes and instance buffers have used since 0.17.0: the floats are stored into wasm linear memory and copied out in a single call. The uploaded bytes, the retained-run upload skip and buffer growth are unchanged, and the desktop path still stages in one bulk copy (#1221).
