- A skinned model whose pose is held is neither sampled nor has its joint palette rebuilt: playback speed 0, a finished one-shot clip resting on its last frame, nothing crossfading. `AnimationPlayer.updateIfChanged` returns the new pose, or null when it would equal the last one, and `AnimationSystem` keeps the palette it already has. A model whose clip is playing, an idle loop included, is posed every frame as before.
