- **`KeyframeAnimationSystem` starts each track's key search where the last frame ended (#1428).** It scanned every position, rotation, scale and alpha track from key 0 on every frame, which a headless host still runs because colliders, sockets and the network read the moved node. Each `KeyframeAnimation` now keeps each track's last key, so a frame costs a key or two per track however many keys it has; a loop that starts over searches from key 0. The sampled values are unchanged.
