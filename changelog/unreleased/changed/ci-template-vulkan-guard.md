- **Pull-request CI catches a starter template that calls a Vulkan API not yet on Maven Central.** A Core release builds the templates against the latest Vulkan release on Central, because the Vulkan family is released by its own tag after Core, so a template using a newer Vulkan API passed pull-request CI and failed the release. When a pull request changes `templates/game` or `templates/project`, the Templates workflow now also compiles their desktop apps against that Vulkan release and the pull request's Core, and fails with a message that the template has to wait for the Vulkan release. `docs/release-process.md` states the rule (#1282).
