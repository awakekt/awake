- Android text input keeps the app visible in landscape (#1770). The keyboard used to open its full-screen extract editor while a text field had focus, which hid the game entirely; `createAwakeInputConnection` now sets `IME_FLAG_NO_EXTRACT_UI` beside `IME_ACTION_DONE`, so the app stays drawn above the keyboard and can lay itself out from the IME inset. A host that wants the extract editor sets the new `Input.textInputExtractEditor`.
