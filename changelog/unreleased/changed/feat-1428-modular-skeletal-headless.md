- **`ModularSkeletalSystem` poses nothing on a headless host and writes its palette in place (#1428).** `ModularSkeletalSystem(hasRenderer = false)` advances every visible modular character's clip, clip switch and crossfade as a host that draws does, but leaves its `SkinnedPose` joint palette as it was, as `AnimationSystem` does. A socket attachment's target, a character tagged `PosedWithoutRenderer`, and a character with no `SkinnedPose` yet are still posed. On a host that draws, a palette that fits the character's skin is now written in place instead of a new one per character per frame, so a posed crowd allocates nothing.
