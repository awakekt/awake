- Vulkan prepares each draw without allocating an object for it (#1742). `prepareGpuDraw` built a `PreparedDrawCall` for every draw on every frame, which the draw preparer copied into the draw's `GpuResolvedDraw` and dropped; it now fills one the preparer keeps. Each further moving, shadowed draw adds 375 B to a frame's garbage on the JVM instead of 463 B, and a 500-draw frame 266 KB instead of 310 KB.
