- **`PipelineVariant` has a new preset, `InstancedTinted`.** It is a sealed interface, so Kotlin code outside the engine that matches every `PipelineVariant` in an exhaustive `when` without an `else` no longer compiles until it handles the new preset; compiled code still links (the binary-compatibility check reports nothing removed) and fails only if the new preset reaches such a `when`. Depth passes now tell a particle caster by its per-instance frame buffer rather than its colour buffer, since a tinted instanced prop carries colours too (#1555).
