- The shadow depth array is allocated only while a light casts shadows, at the shadow budget's map size, on Vulkan and WebGPU (#1698). Before, a renderer whose plan had a depth pre-pass held the array from start, whether or not anything cast: three 2048-texel cascades in 0.54.0 (48 MiB), and all 28 layers (448 MiB) before that. Now it is a one-texel placeholder (bytes, not MiB) until the first frame that draws a shadow. It then holds the layers drawn at `ShadowBudget.mapSize`, so `ShadowBudget.Reduced`'s 1024 texels now take effect (12 MiB for three cascades instead of 48 MiB). It is freed again after 300 frames without a shadow. Allocating or freeing it waits for the frames in flight once, a one-frame hitch; a scene that switches its shadows off and on within those 300 frames keeps the array. The default map size is unchanged: `ShadowBudget.Default` is 2048, so a consumer that never sets a budget gets the same shadows, from the first shadowed frame. `Renderer.shadowMapBytes` reports the bytes held. To keep the array allocated across long shadowless stretches, keep a shadow-casting light enabled.
