- **WebGPU uploads on the web no longer cross into JS once per value.** On Kotlin/Wasm the backend's texture, mesh, font-atlas, instance-buffer and uniform uploads made their JS `ArrayBuffer` one element at a time; they are now stored into wasm linear memory, a word per store, and copied out in one call. A 1024x1024 RGBA texture's buffer took 58 ms and now takes 3 ms in Chrome, which shortens the frame that attaches a newly loaded model's textures, or a terrain layer or a font.
