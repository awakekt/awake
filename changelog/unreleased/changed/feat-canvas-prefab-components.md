- **Canvas prefabs built in code save the component set.** `canvasPrefab { … }` and its kind functions now write each element as `canvas_rect` and the other canvas components it needs, the form a world saves, so a built prefab loads and saves back unchanged. A setting the element's kind never uses, such as a Panel's `sweep`, is reported as one that does nothing and is not saved, where before it was saved and ignored. The game UI guide has a migration note for files, prefab code, code that reads elements and kinds (#1088).
