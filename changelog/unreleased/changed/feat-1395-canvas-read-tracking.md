- **Declarative canvas content follows the state it reads (#1395).** `CanvasContentSystem` now recomposes a `canvasContent` block on a frame where tracked state its last pass read has changed: the `StateFlow` or `Store` it was made from, a `mutableStateOf` it read, or a flow it read through `collectAsState()`. `canvasContent(world, root) { … }` follows what its block reads instead of waiting for `recompose()`, which stays for changes it cannot see, such as a plain `var`. The `StateFlow` and `Store` overloads keep their signatures, and a frame with nothing changed still writes nothing.
