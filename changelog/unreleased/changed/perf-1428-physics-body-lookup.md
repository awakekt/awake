- **`PhysicsSystem` no longer looks each body up in hash maps every fixed step (#1428).** It kept a body's entity, built motion type and poses in three `LinkedHashMap`s keyed by the boxed `BodyHandle`, and read them per body per step, and it found each body's `Transform` by hashing the class. A body is now one record, found during the scan by its entity's slot (an array read) and during the pose readback by its handle id in a primitive `androidx.collection` map. The `Transform` type id is resolved once per world generation, and the readback visitor is built once, not per step.
