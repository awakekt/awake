- **A moving draw's own uniform block is packed without new arrays.** `drawBlockFloats` built a `UniformWriter`, and so a new float array, for every draw it packed, and a textured or lit-shadow draw a material payload copy besides: per draw, on every frame the draw moved, on both backends. A consumer measured the writer's arrays at about 116 KB a frame in a populated 3D scene. `DrawBlockWriters` keeps one writer per draw-block layout and the payload arrays, and the new `drawBlockFloats(drawBlockFloats, alphaToCoverageEnabled, instancedKind, writers)` packs into them; Vulkan and WebGPU each keep one. The block's floats are unchanged, and the array it returns is the writers' until the next pack of that layout.
