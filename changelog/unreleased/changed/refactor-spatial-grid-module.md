- **`SpatialGrid` moves to `com.awakekt.awake.core:spatial` (`com.awakekt.awake.core.spatial`), with `BoundedVolume` in `com.awakekt.awake.core:math`.** `SpatialGrid` and `DEFAULT_SPATIAL_CELL_SIZE` now live in `:awake:core:spatial`, depending only on `:awake:core:math`, so spatial AABB, range, frustum and volume queries can be used without the scene or render modules. `BoundedVolume` in `:awake:core:math` (`ShadowCasterVolume` implements it) backs a general `SpatialGrid.queryVolume(volume, out)`. `:awake:scene:scene3d` keeps `SpatialIndex` and `SpatialIndexSystem`, and keeps `com.awakekt.awake.scene.rendering.spatial.SpatialGrid` and `DEFAULT_SPATIAL_CELL_SIZE` as deprecated forwards to the core grid, with every 0.27 member and JVM signature, so code compiled against 0.27 keeps linking; they stay for binary compatibility until 1.0. `SpatialIndex.grid` keeps its 0.27 type, exposes the core grid as `grid.core`, and a new `SpatialIndex(coreGrid)` constructor builds one over a core grid (#1025).
