- ECS systems no longer box every entity they visit to find new ones (#1742). `ShaderEffectSystem`, `TerrainContentSystem`, the project's audio listener and its character sensor bodies handed `World.queryEach` a function kept in a field, which is called through its generic `invoke` and boxes each `Entity`; they now write the lambda at the call, which the inline query inlines. A desktop JVM's escape analysis hid the cost, which Android pays, so `verifyInlinedQueries`, part of `awakeVerify`, now rejects an ECS query handed a function object.
