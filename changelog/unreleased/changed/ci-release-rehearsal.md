- **A release cut is rehearsed before its tag spends the version number.** A `release-cut/*` pull request now runs the Publish workflow as a rehearsal that uploads nothing: Verify, Consumer (the starter templates built against the latest Vulkan release on Maven Central) and the natives the release collects, on the runners the tag's run uses and at the release's version. It must be green before the cut is merged. The publish run's Verify moved to Linux, so a release waits for one fewer macOS runner; a publish run whose failed jobs never got a runner is re-run once, automatically, by the new Publish recovery workflow; and a pull request that changes build-logic runs its tests on macOS too. `docs/release-process.md` says when a failed publish may be re-run: only when it never reached an upload (#1285).
