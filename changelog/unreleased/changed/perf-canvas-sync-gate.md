- **Canvas sync runs once per change, not three times per frame.** `SceneCanvas` and the runtime input and action systems now call `World.syncActiveCanvasElements()`, which reconciles the canvas only when a component, an element or an element's visibility changed, and leaves elements inside hidden windows alone until they show again; `syncCanvasElements()` still reconciles every element. `ComponentStore.revision` counts a store's adds, replaces and removes.
