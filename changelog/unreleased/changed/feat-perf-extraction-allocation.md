- **Scene extraction allocates zero bytes per visible entity in steady state.** `SceneDrawCollector` reuses draw commands, scratch bounding boxes, and scratch transformation matrices from object pools instead of allocating new `RenderDrawCommand`, `Aabb`, and `Mat4` instances per visible entity each frame. `World.componentStore(typeId)` exposes direct component storage to hoist lookups outside hot extraction loops, component type IDs and entity families are cached across frames when the world instance is unchanged, and `MeshBounds.writeWorldBounds` writes transformed bounds directly into caller-provided bounding boxes.
