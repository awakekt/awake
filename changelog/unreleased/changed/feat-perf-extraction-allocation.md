- **Scene extraction allocates zero bytes per visible entity in steady state.** New reusable `ScratchPool` in `awake:core:math` manages frame-scoped object pools with zero heap allocations in steady state. `SceneDrawCollector` adopts `ScratchPool` for draw commands, scratch bounding boxes, and scratch transformation matrices. `World.componentStore(typeId)` exposes direct component storage to hoist lookups outside hot extraction loops, component type IDs and entity families are cached across frames when the world instance is unchanged, and `MeshBounds.writeWorldBounds` writes transformed bounds directly into caller-provided bounding boxes.
