- **Vulkan builds each resolved draw once.** Its draw preparer built a draw's `GpuResolvedDraw` and then copied it to set the depth-pass fields, two or three 23-field packets per draw per frame, and `prepareGpuDraw` built a slot-counting map on every call it was given an explicit slot. A consumer measured the copies at about 6% of a populated 3D scene's frame garbage. `PreparedDraw.toGpuResolvedDraw(depthRenderKey, alphaCutoff, depthPipeline, depthMaterialBinding, depthJointPaletteBinding)` takes those fields at construction, and the preparer uses it; the packets it resolves are unchanged.
