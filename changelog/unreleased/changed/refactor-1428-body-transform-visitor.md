- **A physics step reads every body back without boxing its handle (#1428).** `PhysicsWorld.forEachBodyTransform` takes a Kotlin function of `BodyHandle`, a value class, so each call boxed the handle: 24 bytes per awake body per fixed step, 28.8 KB a step and about 860 KB a second at 1,200 bodies. The new `PhysicsWorld.visitBodyTransforms(BodyTransformVisitor)` hands each body's handle over as its raw `Long` id with the same scratch pose. Every Jolt backend implements it directly, and `PhysicsSystem` reads poses through it, so a step allocates nothing. `forEachBodyTransform` is unchanged, and the new member has a default that delegates to it, so a backend written against the old interface keeps working.
