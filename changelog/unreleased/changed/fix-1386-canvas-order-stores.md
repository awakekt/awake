- **A scene canvas no longer hashes a component type for every path node of every element each frame (#1386).** `CanvasItemOrder` checks, every frame, that each element's path is as its last sort left it, and it looked each node's `Transform`, `CanvasElement` and `CanvasScaler` up through `world.get`, which hashes the type's key on every call. With about 4,000 elements that was 3–4% of a web frame. It now resolves the type ids once per world generation and takes the three stores once per frame.
