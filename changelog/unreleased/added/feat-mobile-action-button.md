- **A canvas Button can be an action button.** Its new `button` settings (`CanvasButton`) fire `action` on a `Tap` or the moment it goes `Down`, report `consumeDown()`, `consumeRelease()`, `consumeLongPress()` and `heldSeconds`, and press a `longPressAction` and a `releaseAction` in a played project. Its live `cooldown` (0 to 1) sweeps a shade over it and its `charges` show in a badge, set from code or bound with `bind.cooldown`, `bind.cooldownMax`, `bind.charges` and `bind.enabled`; a cooling button with no charge left takes no press, and `consumeReady()` says when it is usable again. `enabled: false` disables a Button, drawn in the new `style.disabled` look. Each action button follows only the pointer that landed on it first (#878).
