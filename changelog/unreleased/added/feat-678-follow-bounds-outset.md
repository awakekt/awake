- **A `followBounds` element can reach past the node it frames.** `followOutset` grows the box on each side by that many dp, so a target marker's corner pieces, anchored to its corners at offset 0, sit outside the node: one box follower instead of four point followers whose offsets a game recomputes from the camera every frame. A negative outset pulls the box in, never below nothing. It's 0 by default and isn't written to a saved scene unless set.
