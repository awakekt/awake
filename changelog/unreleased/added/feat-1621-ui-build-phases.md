- `SceneSystemObserver` now reports the UI host's stages in marks of their own: `ui:compose`, `ui:measure` and `ui:draw`. `ui:build` is ended before each stage and begun again after it, so it holds only what runs between them (input dispatch, focus, semantics, the scene canvas), and no mark encloses another. `ComposeHost.frameStages` (`ComposeFrameStages`) is the hook a host installs for the same split. With no observer installed, nothing is called (#1621).
