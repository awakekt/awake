- **A canvas element is made of focused components.** `CanvasElement` now holds a `CanvasRect` (where it sits), and optionally `CanvasText`, `CanvasAppearance`, `CanvasLayout` or `CanvasCluster`, `CanvasBinding`, `CanvasFollow`, `CanvasFollowArrow`, `CanvasInput`, `CanvasTooltip`, and one `CanvasWidget` (`CanvasButtonWidget`, `CanvasBarWidget`, `CanvasSweepWidget`, `CanvasStepperWidget`, `CanvasJoystickWidget`, `CanvasTextFieldWidget`, `CanvasViewWidget`, `CanvasLookAreaWidget` or `CanvasImageWidget`), read with `get<T>()` and set with `set(component)`. Its live input (taps, hover, drag and drop, wheel, links, focus, stick, look and aim) is in a runtime-only `CanvasPointerState`. `kind` now follows from the components: the widget's, else `Text` with words, else `Panel`. The flat properties read and write the components, so existing code keeps working, except that an option set for another kind is no longer kept: a Button's `camera` or a Panel's `text` reads its default (#1088).
