- **Diagnostics: debug sources.** The new `com.awakekt.awake.core:diagnostics` module is the contract a game uses to show things about itself while it plays. A `DebugSource` (an `id`, a `title`, `rows(out: DebugRows)` and `lines(out: DebugLines)`) is a view of a probe's counters, and writes readings and world-space lines into sinks a host owns and reuses, so it allocates nothing per frame and depends only on `Vec3f` and `Color`. A `DebugRegistry` holds the sources a game has and turns on only the ids in its `enabled` set, so a source that is off is never called. `DebugFlags` reads those ids from `?debug=a,b` on the web or `--debug=a,b` on desktop. The hosts that draw sources (a line host and an overlay) and a world-partition source follow (#1218).
