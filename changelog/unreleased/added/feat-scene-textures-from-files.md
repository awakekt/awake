- **A scene's sprites and tilemaps draw textures from a project's files, loaded when first drawn.** A scene drew a `sprite` or `tilemap` only from a texture registered by name when it was built, and threw `No scene texture named ... is registered` on every frame for any other, so a host whose textures are project files loaded later, such as an editor, couldn't draw them. `SceneAssetResolver.texture(name)` now supplies one as a `SceneTextureLoad` (loaded, loading or failed), and `AssetSourceTextureResolver` reads and decodes each from an `AssetSource` off the frame the first time it is drawn; `runProject` installs one with the project's files. A registered texture still comes first. A texture not loaded yet draws nothing and is logged once as not drawn yet, then draws from the frame it arrives; one that fails to load, or that nothing supplies, draws nothing and is logged once as an error. Neither throws. `SpriteRenderBatch` and `TilemapRenderBatch` take a resolver that returns null for a texture not available yet, and ask again on the next frame.
