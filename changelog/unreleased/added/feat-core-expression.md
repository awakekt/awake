- **Formulas as data: a safe, deterministic expression language (`awake:core:expression`).** A game can now write a number as a formula string in its data, such as damage from attack and defence, an experience curve or a drop weight, and a plugin takes it as a `Formula`, the same interface Kotlin code implements. `Formula.compile` parses once, checks the formula against the variables a plugin declares with `formulaVariables { }`, folds its constant parts, and evaluates without allocating. The language has numbers, `+ - * / % ^`, comparisons, `and`/`or`/`not`, `if(c, a, b)` and a fixed set of functions (`min`, `max`, `clamp`, `floor`, `ceil`, `round`, `abs`, `sqrt`, `pow`, `log`, `lerp`, and `random` drawing from a caller-supplied seeded source); it has no loops and reaches nothing else. Every problem carries a kind, message and position, `Formula.check` lists them for an editor, and `FormulaSerializer` validates a formula as data loads. `log` and `^` are computed from IEEE operations every target rounds alike, so a server and its clients get the same bits on the JVM, Android, iOS and wasm. Limits on length, nesting and size bound every formula, and `UndefinedMath` chooses whether `x / 0` and similar give 0 or throw.
