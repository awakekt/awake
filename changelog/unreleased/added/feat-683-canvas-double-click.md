- **A canvas Button can act on a double-click.** `canvas_element` gains `doubleAction`, fired by two presses within half a second (`CanvasElement.DOUBLE_CLICK_SECONDS`); the second press still fires `action`. A played project presses a `doubleAction` that names one of the scene's input actions, as it does `action`, and game code can read any other with `CanvasElement.consumeDoublePress()`. An inventory can now equip on double-click and select on a click.
