- **A canvas image can load the first time an element drawing it shows: `CanvasImage.lazy` (#1448).** `loadCanvasImages` leaves out a path every element names lazily, so an item-icon atlas or a portrait sheet only a closed window uses no longer adds to a scene's first load. A played project's runtime now gives `SceneCanvas` its image cache, so the image is read when an element using it first shows; until it has decoded, the element draws without it. `AssetImages.asMap()` gives a host that draws `SceneCanvas` itself the same map. A host with no renderer still checks every image.
