- **A node spawned into a played project can draw a model its scene didn't load.** `spawn(project, node)`, which a capability's `SceneHostServices.spawn` calls too, loads a glTF model the scene never named from the project's files, off the frame thread, instead of failing. The node is in the scene at once, and the model's renderer is attached, and its clip started, on the first frame after the model has loaded. A model loads once, however many nodes wait for it, and stays loaded, so the next node that draws it draws at once and shares its mesh, as a model the scene loaded does. A model that can't be loaded is logged as an error naming it and the node, which stays in the scene without it.
  - `SceneAppLifecycleRuntime.spawn(node, componentRegistry, attachNow)` leaves off a spawned node the renderers `attachNow` turns down, `SpawnedNode.attachRenderers(which)` attaches them later, and `SpawnedNode.unattachedRenderables` lists those still waiting.
  - `GltfAssetResolver.adopt(path, from)` takes a model another resolver preloaded, so a host preloads off the frame thread and resolves on it, and `isPreloaded(path)` says whether a model is there.
