- **Diagnostics: debug source lines.** `DebugVisualizationSystem` takes a `DebugRegistry` and draws the lines of every debug source that is on in the same `drawDebugLines` call as its own toggles, so neither wipes out the other's lines; with no source on it draws what it did before. `DebugLineBuffer` holds a frame's lines and keeps them from frame to frame, so steady frames allocate nothing, and caps them at the renderer's line ceiling, counting what it drops. An editor drawing its own lines merges them in the same buffer (#1218).
