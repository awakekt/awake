- **A player can toggle running with a key.** `movement_control` gains `runMode` and `runKey`. `Hold`, the default and today's behaviour, runs while `runKey` (default `Shift`) is held. `Toggle` starts running, and each press of `runKey` switches between walking and running, as in games where characters run unless the player chooses to walk. Typing into a text field leaves a toggle as it was. `MovementControl` carries both, and `PlayerInputSystem` reads them per player.
