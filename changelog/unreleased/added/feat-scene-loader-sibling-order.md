- **`SceneLoader.fromWorld` writes siblings in a host's order.** It wrote a node's children, and the roots, in the order the world stores their `Transform`s, so an editor whose hierarchy lets siblings be moved had to sort the exported document itself, matching each node back to its entity. It now takes an optional `siblingOrder: Comparator<Entity>`, as `SceneCanvas` does: siblings are written in that order, and those it calls equal keep the world's. Without it, nothing changes.
