- **A scene reloads a sprite or tilemap texture it forgets, so an edited image redraws.** A texture was kept for the runtime's lifetime once loaded, so an image edited on disk never redrew, one that failed and was then fixed was never tried again, and another project played in the same runtime with the same paths drew the first one's images. `SceneAssetLibrary.forgetTexture(name)` and `forgetTextures()` now forget one texture or all of them: the sprites and tilemaps destroy what they uploaded from it, each resolver drops what it kept (`SceneAssetResolver.forgetTexture` and `forgetTextures`, which `AssetSourceTextureResolver` implements, dropping a load still in flight), and the next frame asks again, reading the file again. A host calls them on the frame thread when a file changes or its files switch to another project. `SpriteRenderBatch` gains `forgetTexture(name)` and `forgetTextures()`.
