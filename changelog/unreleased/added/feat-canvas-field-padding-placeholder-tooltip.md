- **Canvas text fields get a placeholder and an inner padding, and any canvas element a tooltip.** A `TextField` element's `placeholder` is a text key shown muted while the field is empty and unfocused, and its `padding` (default 12 dp across, shadcn's input, and 0 above and below) keeps typed text off the edge: the caret, selection and scrolling work inside it, and the field now clips at its edge like `BasicTextField`, so a leading `j`'s tail and an `Å`'s ring are no longer cut. Existing text fields draw their text 12 dp further in and have 24 dp less room for it, so a field sized exactly to its value now scrolls; set `padding` to `{ "horizontal": 0 }` (`CanvasPadding.None`) to keep the old layout. Any element's `tooltip` is a text key shown near the pointer after half a second over it, kept inside the canvas and hidden by a press or when the pointer leaves. The three fields are on `CanvasElement` and `canvas_element`; scenes saved without them load with the defaults (#1035).
