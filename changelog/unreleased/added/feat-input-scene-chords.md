- **A scene's `input_actions` take chords.** A button action's new `chords` holds key chords such as Ctrl+1 and controller chords such as a shoulder held with a face button, in the same JSON form as a saved `InputBindings`. A chord is validated like a key: one bound to two actions is refused, and a chord with no modifiers is the plain key. Exporting a scene now keeps the chords a player rebound while it ran, where it dropped them before. A scene written before chords loads as it did (#887).
