- **Messages write numbers the player's way, and pick a branch by ordinal.** `{n, number}` now writes a number with its locale's separators and minimum grouping (`1,234.5`, `1.234,5`, `1 234,5`, and `1234` in Spanish), and takes the styles `integer`, `percent` (`45 %`, `%45`) and `compact` (`1.2K`, `1,2 Mio.`, `1.2万`, or ICU's `::compact-short`). A plural's `#` is written the same way, so `1,000 items` in English and `1.000 Punkte` in German; a plain `{n}` is unchanged. `{rank, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}` picks a branch by the CLDR ordinal category, through the new `OrdinalRules`. The new `NumberFormat` and `NumberStyle` write numbers outside messages. The data is Unicode CLDR 48's for every language `PluralRules` covers, generated by `./gradlew :awake:core:localization:generateCldrNumberData`; another language uses CLDR's root format. `MessageFormat.format` gains `ordinals` and `numbers` parameters and a `format(arguments, locale)` overload, and `Strings.load` an `ordinalRules` parameter. Code that called `MessageFormat.format` with only plural rules now writes `#` with CLDR root grouping (`1,000`).
