- **A many-followers showcase to measure world-following UI.** The engine showcase's new `many-followers` demo puts name plates over 100 to 1,000 walking cubes. The plates are culled, capped, scaled, faded, pinned to the edge, and hidden behind walls by physics rays. It has an on-screen frame-time readout. A benchmark sweep (Debug → Run benchmark, or the `benchmark` launch option) prints one `BENCH` line of frame-time, UI and CPU percentiles per follower count, with occlusion on and off. The showcase now takes launch options on every platform: Android intent extras, iOS scheme environment variables (`AWAKE_SHOWCASE…`) and a browser query (`?showcase=…&benchmark=true`), as well as the desktop's `-P` properties.
