- **Cooked textures in a played project.** A sprite or tilemap texture whose image ships cooked to KTX2 beside it loads from the cooked file: the mobile ASTC or ETC2 file on a device that samples it, else the Basis Universal file transcoded to the device's block format, or decoded to RGBA8 where it takes none. `CookedTextureLoader` (`awake:asset:texture-ktx-loader`) does the lookup, `AssetSourceTextureResolver` takes it as a loader tried before the image, and `createImageMaterial` uploads a `GpuImageSource` that is already block-compressed as it is (#1211).
