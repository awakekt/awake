- **A trackpad pinch is a typed gesture, on the web and on macOS desktop.** `InputSnapshot.pinch` is a `PinchGesture`: the frame's zoom `scale` (above 1 zooms in, and steps multiply), `zoomDelta` (`ln(scale)`), and the `focusX`/`focusY` it zooms about. A host feeds it with `Input.addPinch`. In the browser, a pinch still arrives as Ctrl held with a scroll (#905), and now also as `pinch`, whose `zoomDelta` equals that frame's `scrollDeltaY`; a Ctrl+wheel with Control really held is not a pinch. Safari's `gesturestart`/`gesturechange`/`gestureend` arrive as `pinch` and no longer zoom the page. On macOS desktop the trackpad's magnify gesture, which GLFW does not report, arrives as `pinch` about the cursor. Read the pinch or the scroll, never both: on a frame with a pinch, zoom by it and ignore that frame's scroll. `GameplayInput.pinch` withholds it while the UI holds the pointer or a modal is open, and `CameraSystem` and `CameraInputProcessor` zoom by it in place of that frame's scroll (#891).
