- Launch options, declared once: a `LaunchOptions` schema in `awake:core:config` names each option a game reads at launch, with its type, default, range or choices, description, aliases, and whether it is for development builds only or secret. It reads the parameters any host already parsed (`LaunchParameters.toMap()`). Names match ignoring case and `-`/`_`. Unknown names, refused values, development options in a release build and `--name value` written with a space are returned as `problems` and never thrown. Reads allocate nothing, `describe()` writes the help text, and a feature reads the values through `FeatureHost` (#1556).
