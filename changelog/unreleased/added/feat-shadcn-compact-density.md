- **shadcn components have a Compact density.** A dense UI, such as an editor, used to pass a small size at every call, and inputs, selects, checkboxes, switches and menu rows had no smaller size to ask for. `LocalShadcnDensity` is a `CompositionLocal<ShadcnDensity>`, `ShadcnDensity.Default` when nothing provides one, so an existing UI is unchanged. Under `ShadcnDensity.Compact` every component's default size drops a step: buttons and button group members are 32dp (`Sm`) and inputs, input groups, comboboxes and select triggers 28dp with `px-2`; textareas start at 48dp; select, combobox, dropdown and context menu rows are 28dp; checkboxes and radios are 14dp and switches 28 by 16dp; toggles are 32dp and toggle group items `Sm`; tabs of every variant are `Sm`; table heads are 32dp and list rows (`ShadcnItem`, the command palette) `px-3 py-2`. Labels, field labels and descriptions are `text-xs`, and field, field group, field set and popover spacing tightens. A size passed explicitly still wins, so the `size` parameter of `ShadcnButton`, `ShadcnToggleGroup` and `ShadcnTabs` is now nullable and `null` means "follow the density". Colours, radii and the type scale do not change with density, and no baseline changes at `Default`. `ShadcnTabs` now applies its `size` to the `Pill` and `Line` variants as well as `Ghost`, which used to ignore it. The shadcn guide and README show the two densities side by side.
