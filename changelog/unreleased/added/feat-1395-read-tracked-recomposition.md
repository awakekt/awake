- **Read-tracked recomposition in the Compose runtime (#1395).** A `Composition` pass records the `State` objects it reads. Writing a different value to a `mutableStateOf` it read invalidates it, and `Composition.isInvalid` lets a host compose only then; `Composition.invalidate()` covers changes no state carries. A `PolledState` covers sources the runtime cannot see written: the composition re-reads it to decide. `:awake:compose:state` adds `StateFlow.collectAsState()` and `Store.collectAsState()` on top, with no coroutine collecting the flow. Invalidation covers the whole composition, and `ComposeHost` still composes every frame. Recording a read allocates nothing in steady state.
