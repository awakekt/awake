- **GPU buffers created per frame show in the frame stats.** `Renderer.frameBufferCreations` (a new `BufferCreationStats`: `argumentBuffers`, `instanceBuffers`, `uniformBuffers`) reports the buffers the draw path created during the last frame, by site, on WebGPU and Vulkan; a warm frame reads zero, so a figure that stays up names the pool that is not holding. `SceneFrameStats.bufferCreations` carries it (null when headless or uncounted), `FrameBreakdownSample.bufferCreations` (a new `FrameBufferCreationSample`) feeds the `argumentBuffersCreated`, `instanceBuffersCreated` and `uniformBuffersCreated` keys of `FrameBreakdown`, and the engine showcase's stats card shows them. WebGPU's count of per-draw uniform buffers now includes the ones `uniformSlotForDraw` makes, which it left out (#1621).
