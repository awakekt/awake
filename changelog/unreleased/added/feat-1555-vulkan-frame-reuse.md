- Vulkan `Renderer.redrawsStillFrames`, off by default: when on, a still scene's last prepared frame is drawn again without folding, preparing or sorting anything, as on WebGPU since #1581. A reused frame still reads the frame slot it was prepared in, so the first batch prepared after one waits for every frame in flight before it writes. Opt-in until a run on a real GPU with the Vulkan validation layers on reports nothing; with it off, every frame is planned as before (#1555).
