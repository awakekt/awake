- **One release workflow for every repository.** `.github/workflows/release-reusable.yml` runs the `release-cut` plugin's two-step release for any Gradle repository: a dispatch cuts the release and opens the `chore(release): cut <tag>` PR, and merging it tags the squash commit by its full SHA. It takes `channel`, `bump`, `runs-on` (JSON labels, for self-hosted runners), `java-version`, `gradle-args`, `milestone` and `dry-run`, refuses while another cut is open, and explains a missing or under-scoped `RELEASE_TOKEN` (Contents, Pull requests and Workflows) without printing it. Core's own Release workflow now calls it; `docs/templates/release.yml` is the caller to copy, and `docs/release-process.md` shows how to adopt it.
