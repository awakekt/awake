- **KTX2 textures in the browser.** `BasisWasmTranscoder` transcodes Basis Universal KTX2 textures in the browser with Basis Universal's own prebuilt WebAssembly transcoder (release v2_50, Apache-2.0), which `awake:asset:texture-ktx-loader` ships unchanged and loads only when the first KTX2 texture does. With WebGPU's texture-compression features it feeds `createKtx2Material` BC7, ETC2 or ASTC, and RGBA8 otherwise (#1211).
