- **Canvas prefabs get typed element handles shared by the builder and the binder.** Declare a widget's elements once as a `CanvasWidgetParts` in `awake:scene:canvas`, with groups and `list`s of parts for repeated ones such as slots; each part's id is composed from the declaration (`bar.slot-3.icon`) or pinned to an id a prefab already saves. `canvasPrefab` and the builder's kind functions take the handles and save the same plain string ids, so scene documents, editors, themes and overrides are unchanged. `resolve(world, root)` binds one placed copy in a single pass and throws a `CanvasPartResolutionException` naming each missing or wrongly kinded part instead of a lookup that returns null; each handle (`CanvasImagePart.image`, `CanvasBarPart.value`, `CanvasButtonPart.cooldown`, ...) exposes only its kind's fields and writes the cached element with no per-frame lookup or string building. `findCanvasElement(root, id)` stays for tools and data-only lookups (#1082).
