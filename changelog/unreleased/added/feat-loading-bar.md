- **A default loading bar.** `ShadcnLoadingBar(label, fraction, error, retryLabel, onRetry)` in `awake:ui:shadcn` draws a loading screen's label over `ShadcnProgress`, a spinner beside the label while the progress can't be measured (`fraction = null`, as while waiting for sign-in), and on failure the error in the destructive colour with an optional retry button. It takes plain values, so an app maps `awake:project`'s `LoadingView` onto it and supplies every text in its own language.
