- **Canvas content places prefabs and binds their parts (#1391).** `prefab(prefab)` in a `canvasContent` block places a canvas prefab, the format an editor saves, where the state says: its root element on the declaration's entity and its tree below, made once per place or `key` and destroyed with it. `prefab(prefab, parts = { MyParts() }) { … }` resolves the prefab's `CanvasParts` declaration once per placed copy and writes the block's overrides through those typed handles on each pass.
