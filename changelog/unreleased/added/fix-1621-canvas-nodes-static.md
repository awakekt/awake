- Scene canvas nodes are marked `StaticTransform` by `CanvasNodeStaticSystem`, part of the scene runtime's infrastructure systems, since nothing reads their world matrix: a HUD of 1,000 canvas nodes no longer costs `TransformSystem` a compare each per frame. A node another element follows by name stays unmarked. `TransformSystem.onMovedStatic`, off by default, reports a `StaticTransform` entity written after it was built, checking one in `staticCheckSlices` (16) of them each frame (#1621).
