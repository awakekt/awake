- **Game code can pitch a character per step: `CharacterController.steppedPitch` (#1417).** Beside `steppedYaw`, it sets `Transform.rotation.x` on the character's next fixed step, records it and blends it between frames the short way, so a flyer climbing and diving is interpolated like its turns. The controller writes no pitch until game code sets it, so walking characters keep their own. `CharacterController.freeFacesIntent` turns a `Free` character toward its intent's horizontal direction by `MovementControl.turnSpeed`, for free movers that should face where they go without game code; it is off by default.
