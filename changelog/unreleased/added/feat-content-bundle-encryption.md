- Content bundles can be encrypted: `ContentBundleWriter(encryption = BundleEncryptionKey(...))` seals each distinct member with AES-256-GCM under an HKDF-derived key and nonce (bundle format 2, project index format 4). Bundles stay byte-identical for the same key and range reads still authenticate one member. `IndexedAssetSource` takes the key through a `BundleKeyProvider` and keeps only sealed bytes in its `ContentCache`. See the Encrypted content guide and D42. A `ContentCache` of your own must prune by `ProjectIndex.cacheKeyOf`, not by an entry's `sha256`.
