- **Loading KTX2 textures.** The new `awake:asset:texture-ktx-loader` module turns a KTX2 file into what a device uploads: `GpuDevice.createKtx2Material` takes the best block format the device samples (BC7, ETC2, ASTC or BC3), uploads the cook's ASTC and ETC2 files as they are, and falls back to RGBA8. On desktop, `LibKtxBasisTranscoder` transcodes Basis Universal with libktx; the module's LWJGL BOM keeps every LWJGL module an app has on one version. The texture cook now stores rows bottom first, as every Awake texture is, and `Ktx2Texture.bottomRowFirst` reads it back (#1211).
