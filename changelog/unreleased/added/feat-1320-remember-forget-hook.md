- **Remembered values can release what they own when the composition drops them (#1320).** A value held by `remember` that implements `RememberObserver` gets `onForgotten()` once when the composition lets it go: its key changed, its call stopped being made, its `key` / `rememberGroup` block went, its node (or one above it) left the tree, or its `Composition` was disposed. `Composition.dispose()` and `LayoutComposition.dispose()` drop a whole tree. `SubcomposeLayoutState` now disposes the subcompositions it stops retaining, and disposes itself when its node leaves. A pass that keeps every value calls nothing.
