- **`PluginArchiveSigner` signs `.awakeplugin` archives on the JVM with the same code hosts verify with.** `signature(entries, key)` returns the `signature.sig` bytes and `sign(archive, key)` adds them to an archive after the reader's own checks, so an archive a host would refuse is never signed. `templates/plugin`'s new `signAwakePlugin` task runs it in its own JVM after `awakePlugin`, replacing the copy of the digest and signing code the template carried.
