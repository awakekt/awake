- **`PluginArchiveSigner` signs `.awakeplugin` archives with the same code hosts verify with.** `signature(entries, key)` and `signedEntries(entries, key)` run on every target; on the desktop JVM, `sign(archive, key)` rewrites a whole archive after the reader's own checks, so an archive a host would refuse is never signed, and `PluginArchiveSignerMain` signs a file from a build. `templates/plugin`'s new `signAwakePlugin` task runs it in its own JVM after `awakePlugin`, replacing the copy of the digest and signing code the template carried.
