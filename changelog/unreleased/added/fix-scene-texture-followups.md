- **A texture can be forgotten from any thread.** `SceneAssetLibrary.forgetTexture` and `forgetTextures` run on the frame thread, and a host's file watcher runs on its own. `requestForgetTexture(name)` and `requestForgetTextures()` are safe from any thread: the scene runtime applies them at the start of the next frame, before its systems and draws run. A host that drives the library itself applies them with `applyRequestedForgets()`. `TilemapRenderBatch` takes an optional `UndividedTextures`, which layers share to log an atlas once between them.
