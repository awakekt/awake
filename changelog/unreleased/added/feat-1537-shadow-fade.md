- `awake:scene:scene3d`, `awake:engine:render`, `awake:asset:shader-pack`: a directional light's shadows fade out over the last share of `shadowDistance` (`light.shadowFade`, default `0.2`) instead of ending on a hard line. **This changes pixels at the far edge of every shadowed scene by design**; set `shadowFade` to `0` to keep the hard end. The fade rides in the fractional part of the cascade count in `cameraForward.w`, so no uniform layout changes (#1537).
