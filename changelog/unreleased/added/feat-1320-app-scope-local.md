- **`LocalAppCoroutineScope` gives app UI the app's coroutine scope (#1320).** `composeAppModule` and a scene's `content { }` host provide the `AppCoroutineScope` an app registers as a service, so UI can remember stores under it with `rememberStore(LocalAppCoroutineScope.current) { … }`: their failures reach the app's `AppErrorHandler` and disposing the app cancels them. Reading it with no scope registered fails with a message saying how to register one. `ProvideAppCoroutineScope` lets a custom host do the same. The compose showcase now uses it instead of its own local.
