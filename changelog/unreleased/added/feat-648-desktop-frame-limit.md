- **A desktop game can be checked in CI as it ships, with no code in the game.** `runVulkanDesktopGame` reads `-Dawake.frames=120`, which plays 120 frames in the window and returns, and `-Dawake.capture=frame.png`, which plays with no window and writes the last frame as a PNG. The capture needs a Vulkan driver but no display. Either run fails with the reason if the engine never starts, so a missing driver or native library can't pass as a short run. That's how a game's obfuscated release can be run on a CI machine.
  - `VulkanEngine.playHeadless(width, height, frames)` plays an app the same way and returns its last frame's pixels. `DesktopRunLimits` reads the two properties, and `runDesktopWindow` takes a `frames` limit.
  - `GraphicsEngine` exposes `isReady`, `startupError` and `readPresentedPixels()`.
