- **Prewarm glTF and GLB models a scene hasn't loaded.** A prewarm of a tree whose renderables name a glTF model the resolver hasn't preloaded now reads and decodes it off the frame thread in `SceneSession.coroutineScope`, adopts it into the scene's resolver on the frame thread, then builds and holds its meshes and materials like any other prewarmed asset. Prewarms and a project `spawn` of the same model share one in-flight load, which closing every one of them, or tearing the scene down, cancels; a model that fails to load is listed in `ScenePrewarm.failed`. In a played project, a node whose models were prewarmed attaches them on the frame it spawns. The new opt-in `SceneAssetResolver.loadMesh(name, scope)` hook returns a `SceneMeshLoad` for a mesh a resolver has to load first, and `GltfAssetResolver.loadModel(path, scope)` starts or joins a model's shared load (#1316).
