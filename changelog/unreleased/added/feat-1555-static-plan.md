- **A still 3D scene is planned once on WebGPU.** When nothing a frame's draws read changed (meshes, materials, placement, the clocks their shaders read, light, environment, camera and viewport), the scene compiler hands back the last frame's pass input without folding, preparing or sorting anything. A backend opts in with `GpuDrawPreparer.redrawsPreparedFrames`; WebGPU does, while Vulkan, whose resolved draws bind per-frame-in-flight storage, keeps planning every frame. Planning a still town of 3,000 renderers took 632 µs a frame on the JVM and now takes 539 µs, the rest being extraction (#1555, #1452).
