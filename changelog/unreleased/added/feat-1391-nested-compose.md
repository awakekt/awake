- **`compose { }` draws Compose UI inside a canvas element (#1391).** Declared in a canvas element's content, it lays ordinary Compose UI out in the element's box and draws it where the canvas draws the element: in its place in canvas order, under the element's own children, with its alpha and follow position. The pointer reaches it through the canvas's hit testing, so an element drawn over it takes a tap first. The block's state reaches it as a closure, and the composition locals open where it is declared are provided over the canvas's, through the new `CompositionLocalProvider(ProvidedLocals)`. `CanvasElement.composeContent` holds it at runtime and is never saved.
