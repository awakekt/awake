- **An asset source can say whether a file is there without reading it.** `AssetSource` gains `exists(path)`. It has a default that reads the asset and reports whether the read worked, so existing sources, lambdas included, compile unchanged. `FileSystemAssetSource` asks the filesystem for the entry instead, `IndexedAssetSource` looks the path up in its index without fetching anything, and `LockVerifiedAssetSource` passes the question on. The project-load warning for a Load Scene naming a missing scene now uses it, so finding the target no longer reads it. A graph that several of a project's scenes use now warns as the first of them loads, not again for each.
