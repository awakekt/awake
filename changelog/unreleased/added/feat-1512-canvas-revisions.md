- Canvas parts count their own changes: every canvas component and widget is a `CanvasRevised` whose `revision` moves when a property is set to a different value and stays put on a write of the value already there, and `CanvasElementBase.contentRevision` combines an element's own fields, its parts and which parts it has, so a host that skips unchanged frames can see writes made straight to a component (#1512). Counting allocates nothing on the JVM or in the browser. A `layout`, `cluster`, `bind` or `particles` write of the instance an element already holds no longer bumps `componentsVersion`.
