- **Agents find a walkable path around buildings, props, water and steep ground on every platform (#1426).** `bakeNavSurface` in `awake:navigation` bakes where an agent can stand from terrain heights with a slope limit, static colliders tested against the agent's height and step height, water deeper than it wades, and no-walk areas, storing a clearance per sample so one bake serves agents of every radius. `NavPathQuery.findPath(from, to, agent, out)` returns smoothed waypoints in a reusable `NavPath`, or the route to the nearest reachable point when the target is walled in or past the node budget; a warm query allocates nothing, and the same query gives the same route on wasm, the JVM and Native. `NavTiledSurface` searches a large region baked tile by tile without seams, and `NavSurfaceCodec` caches a bake as bytes.
