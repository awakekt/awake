- WebGPU keeps the scene pass's opaque draws and each shadow cascade's casters as render bundles. Each pass replays its bundles with one `executeBundles`. A 3,000-renderer static scene goes from 4,038 encoder calls a frame (each a crossing into JS on the web) to 41. Draws read their counts from indirect arguments, so a frame whose culling changes only instance counts rewrites those (one `writeBuffer` per changed cell) and records nothing. A draw entering or leaving re-records only the cell it is in. `CommandRecorder` gains `beginRetained`/`endRetained`, defaulting to no-ops, so other backends record as before (#1555).
