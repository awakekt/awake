- **Canvas elements of the same order draw in hierarchy order.** Two elements with equal `order` drew in the order their components happened to be made, so a label moved below another in the hierarchy could still draw underneath it. `SceneCanvas` now draws them as the hierarchy lists them: a node before the nodes under it, and an earlier sibling, with everything under it, before a later one, which is the order the scene saves them in. The one drawn on top is also the one a tap reaches, and a higher `order` still wins. An editor whose hierarchy can move siblings passes its own order as `SceneCanvas(world, siblingOrder = …)`.
