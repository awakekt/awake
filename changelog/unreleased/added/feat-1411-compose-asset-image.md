- **Compose UI loads an image by asset path, for UI that isn't a canvas node (#1411).** The new `compose:assets` module has `rememberAssetImage(path)`, which returns the decoded `ImageBitmap`, or null until it has loaded, read and decoded once off the frame through `LocalAssetImages`, an `AssetImages` cache; `LocalAssetSource` gives the project's files, and `ProvideAssets` provides both for a host of its own. A played project's UI host provides them with no setup: `SceneAppLifecycleRuntime.assetSource` and `assetImages`, a cache per scene that starts from the scene's canvas images, so a path both name is decoded once, and is freed on a scene switch. A missing path stays null, is logged once and kept as `AssetImages.failure(path)`, and never throws in the frame. Once loaded, an ask allocates nothing.
