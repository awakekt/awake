- **Custom image cursors (desktop).** `core:input` adds `CursorImage` (RGBA pixels + hotspot). A scene application sets `SceneAppLifecycleRuntime.cursorImage` (read by the new `pointerCursorImageOf`), and the desktop host shows it: `runVulkanDesktopGame`, `runDesktopWindow` and the GLFW layer gain an image-cursor path (a new `glfwSetCursorImage` binding backed by `glfwCreateCursor`) that overrides the system `PointerCursor` shape while one is set, and falls back to it otherwise. Browser (`url(...)`) cursors and a per-node `Modifier.pointerCursor(image)` are tracked follow-ups.
