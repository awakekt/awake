- **A scene's text shows in the player's language, and a played project loads its `strings/`.** A `canvas_element` of kind `Text` or `Button` takes a `textKey` in place of `text`, and `textArgs` for its placeholders; a `bind`'s new `textArgs` reads an argument from a component field the game sets, such as a player's name or a count, each frame. The words are the key's text in the active locale and change the frame after `Strings.setLocale`, with no reload. A key no table has shows as the key and is logged once. `loadProject` reads the project's `strings/<locale>.json` tables through its files, as it reads scenes and assets, so they stay indexed by content hash: the device's locale's table and `strings/en.json`, the default, and another only when the game switches to it. `LoadedProject.strings` holds them, and `runProject` shows them in every scene it plays, with no game code; a project with no `strings/en.json` has none. `SceneCanvas` and `CanvasOverlay` take `strings`, and `SceneAppLifecycleRuntime` has `canvasStrings`, for a host that draws the canvas itself. Scenes saved before keyed text load unchanged, and save and load round-trip `textKey`, `textArgs` and `bind.textArgs`.
