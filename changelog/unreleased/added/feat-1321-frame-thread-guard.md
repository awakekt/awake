- **The frame-thread checks run in a debuggable Android app, and cover registering a component type.** `AwakeSurfaceView` turns `FrameThreadGuard.enabled` on when the app is debuggable (`ApplicationInfo.FLAG_DEBUGGABLE`, as a debug build is), before the scene records its frame thread; a release app leaves them off. The first `World.add` of a component type, which registers the type, now throws off the frame thread in a debug build before anything is registered, as `World`'s other structural changes do (#1321).
