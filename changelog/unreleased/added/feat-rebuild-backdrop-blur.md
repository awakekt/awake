- **Rebuilt backdrop blur on top of generic `ImagePassChain` and `:awake:engine:render:effects`.** Backdrop blur is now staged and executed without any backend-specific blur code (D40, Part of #957). The dual-filter Kawase blur pipeline (`BlurChain`, `BlurEffectShaders`, `BackdropBlurEffect`, `BackdropBlurReference`) executes multi-pass downsampling, upsampling, and frosted-glass compositing across transient render targets via the backend-neutral `ImagePassChain` layer. Panel coalescing (`BackdropGrouping`) batches and shares non-interleaved blurs in paint order and falls back cleanly under `EffectQuality.Off` or exceeded blur limits, fully verified with cross-backend pixel parity and CPU reference testing.
