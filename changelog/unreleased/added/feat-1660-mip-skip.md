- WebGPU: `Renderer.textureMipSkip` leaves the top one or two mip levels out of material textures, PBR maps, compressed material images and content-feature textures (terrain layers) as they upload, for half- or quarter-size GPU images; a compressed chain skips only to a level of whole blocks, and one level skips nothing. `Texture.width` and `height` stay the source size, so pixel rects map to the same UVs, and the new `uploadedWidth`, `uploadedHeight` and `uploadedMipLevels` report the GPU image. UI images, glyph atlases, written textures, render targets, `Nearest` textures and browser images copied on the GPU upload whole. Applies to later uploads; it saves GPU memory, not decode memory (#1660).
