- **KTX2 texture containers.** The new `awake:asset:texture-ktx` module reads KTX2 files in pure Kotlin on every target: mip levels, Basis Universal (ETC1S, UASTC) or GPU block encoding, supercompression and colour space, with `Ktx2FormatException` for a malformed file. `render:contract` adds `CompressedTextureFormat`, `CompressedTextureImage` and the optional `GpuCompressedTextures` capability, through which a backend will take textures that stay compressed in GPU memory (#1211).
