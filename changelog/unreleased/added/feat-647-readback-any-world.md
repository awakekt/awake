- **A readback can render any world, not only the runtime's own.** `SceneAppLifecycleRuntime.readback(world, camera, width, height)` and `readbackAttachment(world, width, height, attachment)` draw another world the way the frame draws the runtime's, through the same render plan, from that world's own camera, its virtual viewport included. An editor can capture the world it plays a scene in, such as a Game view screenshot during Play, so long as the world's meshes and materials came from the runtime's renderer and its systems have run. The existing overloads draw the runtime's own world, as before.
