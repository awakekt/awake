- **Deterministic teardown for protected and encrypted asset sources.** `IndexedAssetSource`, `LayeredAssetSource`, `TokenAuthorizedFetch`, and `BundleKeyProvider.wrapped` now implement `AutoCloseable` so applications and runtime security services can drop cached read tokens, close held bundle key handles and ephemeral RSA-OAEP session keys, and zero uncached staged bundle plaintext without clobbering caller-owned key arrays.
