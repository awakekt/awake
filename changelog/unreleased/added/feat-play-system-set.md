- **An editor can play a scene with the same systems as `playProject`.** `SceneAppDsl.playSystems(scene, physics, particleSprites)` registers the systems a `SceneDocument`'s components call for (movement, physics and characters, the camera rig, spin, locomotion, keyframes, particles, canvas actions and skinned animation), and `playProject` now calls it, so a host that plays a scene in a world of its own no longer keeps a list that drifts when Core adds a component that needs a system. `installPlayableComponents()` installs the controls, physics and character components a host needs before it decodes such a scene; `loadPlayableProject` calls it too.
