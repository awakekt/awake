- **A capability's fixed system can run before the character controller: `SceneSystemPlan.fixed(name, before, create)` (#1417).** `plan.fixed("flight", before = SceneSystemPlan.CHARACTER_CONTROLLER) { … }` runs the system in the same fixed step, just before Core's `CharacterControllerSystem`, so the velocity it writes on a `Free` character's `MovementControl` moves it that step rather than the next. When the named system isn't planned it runs last, as `fixed(name)` does; `fixed(name)` is unchanged. The `MovementDriver.Agent`, `steerPlayers` and `CharacterMotionMode.Free` docs say how a game takes a player's character over without player input overwriting its velocity.
