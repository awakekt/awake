- **Build canvas prefabs in code.** `canvasPrefab(guid, name) { ... }` builds a `ScenePrefab` of `canvas_element` nodes with a typed setting for every field (`Dp` sizes and offsets, an `Sp` font size, `Color` colours) and a function for each kind, so a plugin's HUD covers anchors, layout, text keys, bindings, actions, nine-slice styles, bars, sweeps, steppers and the controls kit. It validates what it builds, and `CanvasPrefabs.toJson` writes the file an editor saves, which loads into a world and saves back unchanged. A new `canvas_element.elementId` gives an element a stable id: `World.findCanvasElement(root, id)` finds it under one placed copy, whatever its name or the copy's, and `ScenePrefab.findCanvasNode(id)` finds it in the prefab. `Color.toHex()` writes the canvas hex form, `#RRGGBB` when opaque and `#RRGGBBAA` otherwise, and `DpSerializer`, `SpSerializer` and `ColorHexSerializer` in `awake:core:schema` save typed sizes and colours as numbers and hex (#889).
