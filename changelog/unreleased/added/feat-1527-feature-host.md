- A feature reads the services its host owns once, when it registers: `FeatureHost` (the same type as `SceneHostServices`) gains `provide<T>(value)`, `require<T>()` and `optional<T>()`. A missing required service fails at load naming the feature, the system and the type, and a system never looks a service up in `update`. `SceneAppDsl.features` takes a `provided` hook for the same on the code-first path (#1527).
