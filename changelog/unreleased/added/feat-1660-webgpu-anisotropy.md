- WebGPU: anisotropic filtering from `Renderer.maxAnisotropy`, up to WebGPU's 16 (`maxSupportedAnisotropy`, which 0.53.0 reported as 1, so the setting changed nothing there). The device keeps every texture it samples, content features' included, so a change remakes each linear, mipmapped texture's sampler, and every material, UI and content bind group built with the old one is built again before it is next bound; `Nearest`, `BaseLevelLinear` and single-level textures keep `maxAnisotropy` 1, as WebGPU requires. Vulkan applies the setting since 0.53.0; `textureMipSkip` is still read by no backend (#1660).
