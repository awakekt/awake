- **Crash recording for web apps, and a seam for sending reports.** On wasmJs, `LocalStorageCrashStorage` keeps a `CrashRecorder` session in the page's `localStorage` (guarded, so blocked or full storage never stops the app), and `installPageCrashHooks(recorder, sampler)` ends the session on `pagehide`, records a breadcrumb when the tab is hidden, and records `error` and `unhandledrejection` events. In common code, `CrashReportSender` is the interface an app implements over its own client (Core adds no HTTP dependency), `CrashRecorder.sendPending(sender)` sends the pending crash and marks it sent only once the send succeeds, and `ErrorSampler` rate-limits and deduplicates errors by key.
