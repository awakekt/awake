- **Per-bundle key overrides in encrypted project indexes.** `ProjectIndexBundle` adds an optional `keyId` override (resolved via `ProjectIndex.keyIdOf` and mixed into `ProjectIndex.cacheKeyOf`) so a single version 4 `ProjectIndex` can seal shared bundles under the index's default `encryption.keyId` and gated region or entitlement-tier bundles under their own keys while keeping existing single-key indexes byte-identical. `ContentBundleWriter` adds `groupEncryption`, `awake bundle` adds `--group-key-file` and `--group-key-env`, `generateContentBundles` adds `projectContent.bundleGroupKey(...)`, and `IndexedAssetSource` keeps one `MemberSeal` per distinct `keyId`, asking `BundleKeyProvider` only when a bundle sealed under that `keyId` is read or prefetched (#1325).
