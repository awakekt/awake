- `TranslatePush` and `TranslatePop` in `:awake:core:graphics2d` open and close a range of UI primitives drawn moved by an offset, so a subtree that moved as a whole can hand on its last frame's primitives instead of a moved copy of each. Both backends' UI staging applies them as it stages, bit-identical to staging moved copies. `rasterize()` applies them too, so screenshot and pixel tests need no change; code that reads primitive positions itself (for example `filterIsInstance<DrawCommand.Glyph>()` then `x`/`y`) reads `primitives.flattened()` instead. An exhaustive `when` over `UiDrawPrimitive` without `else` needs a branch for the two new types (#1512).
