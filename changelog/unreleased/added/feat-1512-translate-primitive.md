- `TranslatePush` and `TranslatePop` in `:awake:core:graphics2d` open and close a range of UI primitives drawn moved by an offset, so a subtree that moved as a whole can hand on its last frame's primitives instead of a moved copy of each. Both backends' UI staging applies them as it stages; `List<UiDrawPrimitive>.flattened()` applies them for code that reads positions, and the test rasterizer reads through it (#1512).
