- **Launch origin and primary input.** `LaunchEnvironment` reports what the host knows about itself, read once at launch: on the web, the page's `LaunchOrigin` (scheme, host and port, `null` for `file:` and other opaque origins), so a game can derive its default server or content address without `js()` interop; and a `PrimaryInput`, `Touch` or `Pointer`, from `matchMedia('(pointer: coarse)')` on the web, the touchscreen system feature on Android, `Touch` on iOS and `Pointer` on desktop. The origin is `null` off the web. Both are documented as hints, not security boundaries (#1139).
