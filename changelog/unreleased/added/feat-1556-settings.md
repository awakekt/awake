- Player settings, declared once: `awake:core:settings` adds a `SettingsSchema` of typed keys, each with a default, a range or choices, a label and the launch option that overrides it. `Settings` resolves each key as default, then saved, then launch option, and reads allocate nothing. Each key is observable as a `StateFlow` for `collectAsState()`. A change is written after a short delay and never on the frame, and only values that differ from their default are saved. Renamed keys (`formerly`) keep the player's value, and unreadable saved text is kept aside. Values are stored through a three-method `SettingsStorage`, by default a file in `awake:core:io` (IndexedDB on the web) (#1556).
