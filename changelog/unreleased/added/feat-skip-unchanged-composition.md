- `ComposeHost.skipUnchangedComposition` (off by default) skips a frame's composition pass when no state it read changed, and the density, viewport, insets, pointer modifiers and layout direction are the same. Reading `FrameClock` and the `InteractionSource` hover, press and focus counts is now tracked, so a pass that read them is invalidated when they change. A frame of 200 world-anchored nameplates drops from 423,578 B to 221,482 B with it on.
