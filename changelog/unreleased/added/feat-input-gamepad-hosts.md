- **Every built-in host reads a controller.** Desktop reads one through GLFW's gamepad API while its window has focus, Android through a controller's key and joystick events (hat d-pad and analog triggers included), the browser through the Gamepad API once a frame for a controller in the standard layout, and iOS through GameController's extended gamepad. Each writes it into `Input.setGamepadButton` by button position and releases every button when the controller goes away. `GameplayInput` now passes controller buttons to the input actions, so a `GamepadChord` on an action fires in a played scene. `Input.setGamepadButtons` and `Input.releaseGamepadButtons` let a host of its own do the same (#887).
