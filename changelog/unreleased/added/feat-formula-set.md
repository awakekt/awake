- **Compile a definition's formulas together, and declare variables in data.** `FormulaSet.Builder` in `awake:core:expression` takes a definition's formula and condition slots, each with a path such as `combat.chances.miss`, its variables and whether it has a random source, and compiles them all: `compile()` gives every compiled slot or every `FormulaSetProblem` (path, source, kind, message and position), and `build()` throws one `FormulaSetException` listing them, one per line. A slot without a random source rejects `random()` when it is compiled, with the new `FormulaProblemKind.RandomUnavailable`. A game declares typed variables in its own data with the serializable `FormulaVariableDeclaration`, which `FormulaVariables.Builder.declare(declarations, prefix = "attacker.")` adds; `FormulaVariables.isValidName` and `validateName` check a name and say why it is not valid (#950).
