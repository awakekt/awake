- **A corner handle can show a diagonal resize cursor.** `PointerCursor` gains `ResizeNorthWestSouthEast` and `ResizeNorthEastSouthWest`, CSS's `nwse-resize` and `nesw-resize`, so `Modifier.pointerCursor` on a top-left or bottom-right corner, or on a top-right or bottom-left one, asks for the arrow that matches it. The desktop window shows them through GLFW 3.4's diagonal shapes; with a system GLFW older than 3.4, or a cursor theme without them, it shows the default arrow.
