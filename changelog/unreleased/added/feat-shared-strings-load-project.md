- **A game and its project share one `Strings`.** Every `loadProject` overload takes an optional `strings`, placed before `physicsWorld` so a trailing physics lambda still binds to it: a game that made its own `Strings` before the project loaded, for a connection screen's text, passes it, and the project's `strings/` tables are added to it at `StringLayer.Game` instead of loading into a second instance. `LoadedProject.strings` is then that same instance, the game's chosen locale is kept, one `setLocale` changes the game's text and the project's together, and the project's keys win over the game's within a locale. The tables are added only once the rest of the project has loaded, so a failed load leaves the game's `Strings` as it was. Without `strings`, loading is unchanged. The previous `loadProject` signatures stay, hidden, for binary compatibility. The Localization guide covers it (#1141).
