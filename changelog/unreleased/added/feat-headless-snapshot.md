- **A headless snapshot helper.** `VulkanEngine.snapshotPng(file, width, height, frames)` plays an app with no window, as `playHeadless` does, and writes the last frame as a PNG, for CI screenshots and pictures in the docs; a project is snapshotted by composing it as usual, `app { scene(...) { runProject(project) } }` with `VulkanEngine(game, ProjectRenderPlan)`. `TextureAsset.writePng(file)` is now public for a frame `playHeadless` returned. It needs a Vulkan driver, or Mesa's lavapipe without a GPU.
