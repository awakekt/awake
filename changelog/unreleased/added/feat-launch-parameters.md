- **Launch parameters and host actions on every platform.** `LaunchParameters` reads what a game was launched with, the page URL query on the web, `--key=value` and bare `--flag` arguments on desktop, an Android launch `Intent`'s data query and extras, and the launch URL's query on iOS, keeping repeated keys as a list of values and bare flags, with one set of parsing rules in common code. `HostActions` is a separate service: `openUrl` for `http`, `https` and `mailto` links on web, desktop (headless-safe), Android and iOS, and `pageReload`, which is `null` everywhere but the web so a game checks for it instead of calling a no-op. Launch parameters are documented as untrusted input (#1139).
