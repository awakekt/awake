- Add a render scale for the 3D scene: `Renderer.renderScale` (in `(0, 1]`, default 1) and a `renderScale` provider on new `launchWebGpuGame` overloads, read before every frame. Below 1 the WebGPU backend renders the scene, its depth and its post-processing into a smaller target and upscales it bilinearly to the canvas before the UI draws at the full device pixel ratio, so text stays sharp; at 1 the frame is unchanged, with no extra target or pass. `Renderer.surfaceWidth`/`surfaceHeight` report the scene target, and the new `Renderer.outputWidth`/`outputHeight` the presented surface that viewports and picking are measured in. `RenderScale` sizes a scene target for a scale. The Vulkan backend does not implement the scale yet and keeps 1.
