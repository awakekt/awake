- **`awake validate --code` opens a project with its own code, as an editor does.** Given the project's built classes or jars, `validate` loads each plugin's `capabilityClass` in a class loader of its own whose parent holds Core, and checks it is a `SceneCapability` with the plugin's id. It then opens every scene with those capabilities through the new `checkProjectOpens` in `awake:project:runtime`: decoded with the project's registry, prefabs expanded, every component known, instantiated, loaded with its content and physics world, and its systems run a step. Each scene and prefab is saved, reopened and compared, and saved again to the same text. Last, the project closes, every physics world it made must be destroyed, and the project's code must not stay loaded. Each problem comes with its file, node path and code, and any error exits 1. Plain `validate` now also checks the engine version the manifest needs and each asset-lock pin's size and SHA-256 (#926).
