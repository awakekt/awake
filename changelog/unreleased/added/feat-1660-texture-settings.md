- Texture settings for a host's graphics options (#1660): `TextureSettings` (`TextureQuality` High/Medium/Low, `TextureAnisotropy` Off to X16, with `TextureSettingsPersistence`), registered with `app { textureSettings { } }` and applied before every frame like `renderQuality { }`, and `Renderer.maxAnisotropy`, `Renderer.maxSupportedAnisotropy` and `Renderer.textureMipSkip`, with `TextureSampling` deciding which textures they reach. The renderer defaults are no anisotropic filtering and full-size textures, so an app that registers no settings renders as before; the backends implement them in the following changes.
