- **A silhouette outline for hovered and selected entities.** Mark an entity `Outlined(set)` and a line is drawn around its edge, over the scene, in that set's style: an editor's selection and hover, or a game's interactable under the cursor. `World.outline(root, set)` marks an imported model's whole hierarchy, and `null` clears it. `OutlineStyles` sets each set's colour and width in pixels; by default set 0 is orange, 3 px, and set 1 a fainter white, 2 px. Set 0 draws over set 1 where they meet. It works on Vulkan and WebGPU, skinned meshes in their pose included, and `ProjectRenderPlan` has it. It costs nothing on a frame with nothing outlined.
  - **Mask pass.** `RenderPlan.maskShaderSet` opts a plan into it: depth from the camera, one layer per mask layer, of only the draws whose `GpuDrawRequest.maskLayer` names that layer. Each layer's sub-pass, `GpuPassInput.maskPasses`, carries that layer's uniforms. The mask is bound at `BindingSemantic.MaskDepth`, which shares the fourth group with the joint palette, because WebGPU guarantees only four groups. A content feature reads it by declaring `samplesMask`.
  - **Outline overlay.** `outlineContentFeature()` is the overlay that reads the mask: a full-screen pass, shared by both backends, that draws each layer's `OutlineStyle` where a pixel is outside the layer's silhouette but within its width of it.
  - `ScenePassCompiler.compile` takes `maskLayers`, and instancing keeps masked and unmasked copies of a mesh in separate batches.
