- **Compressed textures on WebGPU.** The WebGPU backend answers `GpuCompressedTextures` as Vulkan does: it requests `texture-compression-bc`, `-etc2` and `-astc` wherever the adapter offers them, uploads a block-compressed image as it is with its mips, and binds it as a material's base colour. An image whose base size isn't whole 4 x 4 blocks, which WebGPU refuses, is decoded to RGBA8 instead (#1211).
