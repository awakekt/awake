- **A project can start with its entry scene gated.** `loadProject(files, EntryGate(placeholderScene))` loads a placeholder scene, or an empty one when `placeholderScene` is null, when the files gate the entry scene (a `LayeredAssetSource` with no protected source attached yet, say), and `runProject` asks for the entry scene as it starts: the switch reports `SceneSwitchState.WaitingForContent` and plays the entry scene once the app attaches the protected source after sign-in. An app no longer needs its own placeholder scene, switch and source wrapper for a world that only loads after sign-in. A host without `runProject` reads `LoadedProject.pendingEntryScene` and switches to it itself. When the entry scene is not gated, it loads as usual.
