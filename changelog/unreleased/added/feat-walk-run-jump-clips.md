- **Characters run, turn and play clips for how they move.** `movement_control` gains `runSpeed`, used while Shift is held (`PlayerInputSystem` sets `MovementControl.run`), and `turnSpeed`, the radians per second a character turns to face where it moves; both `MatrixRelativeMovementSystem` and `CharacterControllerSystem` honour them. New `locomotion_animation` (`SceneLocomotionAnimation`, loaded by default) names a skinned model's idle, walk, run and jump clips and the speeds between them; `LocomotionAnimationSystem` measures how the entity moves and cross-fades to the matching clip, however it is moved. `playProject` runs it when a scene uses it.
