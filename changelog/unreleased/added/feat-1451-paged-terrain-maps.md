- **A streamed terrain's control map and lightmap page on the same cells as its heights (#1451).** `TerrainLayerPaging.page(index, control, lightmap)` in `awake:kit:terrain-layers` cuts a whole-footprint `.terrainctl` and `.terrainlight` onto the cells of a `paged_terrain` index, one file per indexed cell, plus small centre-sampled coarse maps that draw cells not yet resident, and returns the index naming them. Entering the terrain through `ScenePagedTerrain` and `PagedTerrainSystem` then reads the coarse maps plus the layer and light data of the cells in reach, not the whole maps.
