- **`IndexedAssetSource` can cache a published project's verified files in the browser.** `IndexedDbContentCache` implements `ContentCache` over IndexedDB, keyed by SHA-256: a return visit to the same project doesn't download the files unchanged since the last one. Storage the browser blocks or fills never fails a load: it reads as a miss, and the file comes from the network. Every read and write shares one connection, which lets go when another tab upgrades the store.
