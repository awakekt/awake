- **Game code can face a character per step: `CharacterController.steppedYaw` (#1417).** Reading it gives the yaw the character's last fixed step left it facing, not the blended `Transform.rotation.y` a frame shows; setting it faces the character that way on its next step, recorded and blended between frames like a walking turn. A `Free` character, which nothing else turns, is faced this way, so a flight model can turn it by a rate each step. Walking characters are unchanged unless it is set.
