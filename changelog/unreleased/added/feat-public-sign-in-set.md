- A project can declare a public sign-in set in `projectContent` (`publicScenes`, each with every file it names, and `publicFiles` globs): `generateProjectIndex` then writes a public index next to the protected one, each file in exactly one, and `generateContentBundles` bundles each set into its own folder. `LayeredAssetSource` serves the public set before sign-in and the protected source the app attaches after it, which wins for files both have, with one fetch per read and each layer's SHA-256 checks intact; it prefetches through both layers, so scene-switch progress counts their bytes. A `SceneSwitch` to a protected scene before the source is attached reports `SceneSwitchState.WaitingForContent` and loads once it arrives, through the new `GatedAssetSource` contract, which `LockVerifiedAssetSource` forwards.
