- **Content stages, a content load state and a loading view model.** `ContentStages` stages named groups of files ahead of play, declared as data (`ContentStage`: path-list files, missing paths skipped, an optional fallback list), through any `PrefetchableAssetSource`, with no display, so a server stages the same content as a client. Its `ContentLoad` state (idle, loading with bytes done and total, waiting for content, ready, too new, failed) is separate from `SceneSwitchState`, and `ContentLoad.loadingView()` gives a loading screen its phase, fraction, error and whether to offer a retry. `isTooNew(Throwable)` in `awake:core:io` tells content newer than this build from other failures: `SceneSchemaVersionException` and the new `ContentFormatTooNewException`, thrown for a newer content index, content bundle or project manifest format, implement `ContentTooNew`. `ReadActivitySource` counts reads in flight, and its `awaitQuiet` tells a scene that streams after its first frame when its reads have gone quiet.
