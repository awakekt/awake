- **A visual editor can edit state machines.** `AiRegistry.stateMachineNodeRegistry()` describes machines as an `awake:node-graph` vocabulary, and `StateMachineDefinition.toNodeGraph()` and `NodeGraph.toStateMachineDefinition()` convert a machine to a graph and back. The graph has one machine node carrying its id and starting blackboard, wired to the initial state; a node per state, typed by its kind (`state/ai.state`) and carrying its name, parameters, enter and exit nodes and tree; and a node per transition, in order, wired from the state it leaves (unwired for an any-state transition) to the state it enters. States are known by their name, so an editor may give graph nodes its own ids, and every problem in a graph is listed together. `TransitionDefinition` gains `layout`, so a transition's place on the canvas is kept (#907).
