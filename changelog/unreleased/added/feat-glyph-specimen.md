- **Glyph specimen baselines for the built-in font.** `:awake:compose:ui-testing` now holds snapshots of every glyph `UiFonts.default()` draws at 12, 24 and 48 sp: Regular, Bold and Black at device scale 1 and Regular at 1.5, plus Regular at both scales with each glyph's layout box outlined so ink outside it shows. A change to how text draws re-records them, so its Render Evidence comment shows the before and after. A coverage test reads the code points each weight draws off the atlas, fails when a declared glyph draws as '?', and records which code points the subset covers and lacks per Unicode block. The new `assertMatchesGrayscaleBaseline` records a baseline as an 8-bit grey PNG at the strongest compression, which keeps these sheets to 373 KB in all, and compares it exactly as `assertMatchesBaseline` does (#1055).
