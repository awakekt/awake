- **Text steps by grapheme cluster, so an emoji is never split.** `core:text` gains `GraphemeClusters`, Unicode's extended grapheme cluster boundaries (UAX #29, Unicode 18.0) from a table generated from the Unicode Character Database and checked against Unicode's own `GraphemeBreakTest.txt`: a ZWJ family emoji, a skin-toned emoji, a flag, a keycap, a letter with its combining marks, a Hangul syllable spelled in jamo, an Indic conjunct and CR LF are one character each. `TextFieldState` moves the caret, deletes with Backspace and Delete, and selects one cluster at a time, and a caret or selection set inside a cluster moves to its edge. `Text`, `BasicTextField` and `UiFont.measureTextWidth` measure, paint and hit-test by cluster, so an emoji the font lacks draws as one missing-glyph box rather than one per code point, and a masked field draws one mask per character. `UiFont.ellipsize` cuts a line to a width with "…" between clusters. `TextFieldState.maxLength` limits typing, pasting and IME input, counting graphemes by default or `TextLengthUnit.CodePoints` or `Utf8Bytes` to match a server, and lets an emoji in whole or not at all; a canvas `TextField` sets it with `maxLength` and `maxLengthUnit`. `UiFont` gains `hasGlyph(codePoint)`, `glyphFor(codePoint, weight)` and `advanceFor(codePoint, glyphPx, weight)`, which `PackedUiFont`, `UiFonts.fallback` and `UiFonts.family` answer past U+FFFF, so a font loaded with CJK Extension B characters is found for them, and `Strings.loadFont` bakes fallback fonts by code point (`Strings.codePoints()`). `hasGlyph(Char)` keeps working for the Basic Multilingual Plane. Emoji still draw as missing glyphs until colour emoji fonts arrive.
