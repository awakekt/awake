- **`PointGrid2D` in `awake:core:spatial`: an allocation-free point grid for per-tick neighbourhood queries.** Rebuild it each tick with `clear()` and `add(id, x, z)`, then ask `forEachNear(x, z, radius)` or `anyNear(x, z, radius)`; cells live in an open-addressed table with Fibonacci hashing and the queries are `inline`, so a warm grid allocates nothing. `SpatialGrid` stays the index for boxes and for content kept across ticks; `PointGridBenchmarks` measures the two on the same tick.
