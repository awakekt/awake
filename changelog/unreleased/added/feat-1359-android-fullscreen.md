- **Immersive fullscreen on Android (#1359).** `androidHostActions(activity)` fills `HostActions.fullscreen` with `androidFullscreen(activity)`, which hides the status and navigation bars through the platform `WindowInsetsController`. A swipe from the edge shows the bars briefly without leaving fullscreen. `enter` and `exit` post to the activity's UI thread, so the game loop's render thread may call them, and `isActive` reads the window's insets each time, because the system can bring the bars back by itself. Given the application context instead of an `Activity`, `fullscreen` stays null. iOS is still null.
