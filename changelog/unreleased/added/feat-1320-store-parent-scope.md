- **`core:state` stores can run under a parent scope (#1320).** `CoroutineScope.childStoreScope(dispatcher)` creates a store scope whose `SupervisorJob` is a child of the given scope (normally the app's `AppCoroutineScope`) and which inherits its context. Pass it as the `scope` of `store`, `reducerStore`, `MutableStore` or `MutableEffectStore`, or use the new `DefaultStoreScope(parent, dispatcher)` constructor. Uncaught store failures then reach the parent's `CoroutineExceptionHandler` (the app's `AppErrorHandler`), cancelling the parent cancels every store, and closing a store cancels only that store. Stores created without a parent are unchanged.
