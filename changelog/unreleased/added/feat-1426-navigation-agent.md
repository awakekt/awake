- **A scene's `navigation_agent` walks to a destination around what its `navigation` blocks (#1426).** `awake:scene:navigation` adds the `navigation_agent` component and `NavigationAgentSystem`, which `runProject` runs with nothing wired by the host. The agent re-plans when it is pushed off its route or stops making progress, walks through an `Agent` `movement_control` so a `character_controller` carries it (or by its transform without one), and allocates nothing per frame. Code sends it elsewhere with `NavigationAgent.moveTo`, for click-to-move. A scene with a `navigation_agent` and no `navigation` does not load.
