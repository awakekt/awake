- A system has a role, `SceneSystemRole.Simulation` (the default, run by every host) or `Presentation` (local input, drawing, effects, sound), and a host has a `SceneHostRole`, `Full` or `SimulationOnly`. A `SimulationOnly` host, a dedicated server or a headless simulation, plans none of the presentation systems without the game listing them: Core marks player input, the canvas actions and occlusion, terrain drawing, keyframes, texture and sprite clips, particle sprites and 3D particles, the day cycle, shader effects and audio. `plan.frame(name, role)`, the scene app's `system(name, phase, role)` and `hostRole(...)`, `runProject(project, hostRole)` and `SceneHostServices.withHostRole` set them; a host is `Full` unless set, a `headless` one too, so nothing changes until a server opts in. The camera system stays a simulation system, because movement reads the basis it places (#1527).
