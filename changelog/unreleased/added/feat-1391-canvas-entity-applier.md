- **`CanvasEntityApplier` builds a composition's nodes as canvas entities (#1391).** `:awake:compose:runtime` can now reconcile canvas content: an insert makes an entity with a `Transform` under its parent's, a keyed move keeps the entity and changes where it draws, and a remove destroys it and everything the content made under it. A pass writes only the canvas components that changed, so an unchanged pass writes nothing; `writes`, `created` and `destroyed` count what each pass did. Siblings the content declared draw in the order it declared them, through a runtime-only `CanvasSiblingIndex` that canvas ordering, cached or not, reads before storage order.
