- **Fullscreen as a host capability.** `HostActions.fullscreen` is a `Fullscreen` (`isActive`, `enter`, `exit`, `toggle`) or null where the host can't offer it. On the web, `browserHostActions()` fills it with `browserFullscreen()`, which puts the whole page in fullscreen through the Fullscreen API (falling back to Safari's `webkit` names) and is null when `document.fullscreenEnabled` is false, such as in an `<iframe>` without `allow="fullscreen"`. Desktop, Android and iOS report null. The engine binds no key or button to it, so each game chooses its own control. `fullscreen` has a default getter, so existing `HostActions` implementations still compile and link.
