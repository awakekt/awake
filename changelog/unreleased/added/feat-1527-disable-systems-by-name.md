- Every system a scene plans has a stable name: `CoreSystems` lists Core's, and `SceneCapability.systemNames` lists a game's. A host or consumer leaves systems out by name with `sceneSystemsFor(..., disabled)`, `LoadedProject.sceneSystems(..., disabled)`, `runProject(project, disabledSystems)` or the scene app's `disableSystems(...)`; an unknown name is refused at start with the names that exist. `SceneSystemSet.planned`, `ProjectSystemPlan` and `SceneAppLifecycleRuntime.plannedSystems` list a run's systems in order (#1527).
