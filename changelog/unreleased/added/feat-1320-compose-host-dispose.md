- **Disposing a Compose host releases what its UI remembered (#1320).** `ComposeHost.dispose()` drops the composed tree and tells every remembered `RememberObserver` it was forgotten, so a remembered store is closed when its host goes away. The Compose app module disposes its host when the app is disposed, and a scene app disposes its legacy `content {}` host when there is one, both before their renderer resources are released. A frame after `dispose()` composes a fresh tree.
