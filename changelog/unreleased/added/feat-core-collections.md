- **`SortedLongSet` in `awake:core:pool`.** A sorted set of 64-bit ids refilled every tick without allocating: fill it in any order with `addUnsorted`, `sort()` it once (dropping duplicates), search it with `contains`, and compare two ticks' sets with `SortedLongSet.diff(previous, current, onEnter, onLeave)`, which walks both once and allocates nothing. It is built on `androidx.collection`'s `MutableLongList`. For maps keyed by `Long` without boxing, the pool's README points to `androidx.collection`'s `MutableLongObjectMap`, which Core already uses, rather than a map of Awake's own.
