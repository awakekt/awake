- **`ReusableIdSet` in `awake:core:pool`.** It hands out the smallest free id from `0 until maxIds`, reuses an id once it is released, takes ids from elsewhere with `add`, and visits the ids in use in order with `forEach`; it is a bit set, so steady-state use allocates nothing. For maps keyed by `Long` without boxing, the pool's README points to `androidx.collection`'s `MutableLongObjectMap`, which Core already uses, rather than a map of Awake's own.
