- A Compose host that skips unchanged composition (`ComposeHost.skipUnchangedComposition`, still off by default) can now show state the snapshot system does not observe, such as fields an ECS system writes. `invalidate()` makes the next frame compose. `externalChanges` is asked once a frame whether that state changed, and asking costs an idle frame no allocation. `verifySkippedCompositions` composes the frames that would be skipped anyway and reports through `onStaleSkip` and `staleSkips` any whose output would have differed, with the first differing primitive, so a consumer can find the reads it must invalidate for (#1544).
