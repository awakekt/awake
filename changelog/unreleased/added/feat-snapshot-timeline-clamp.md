- **`AdaptiveSnapshotTimeline` keeps its learned snapshot interval across a pause and can clamp bad inputs.** A pause rebase (a backgrounded tab, say) used to reset `intervalSeconds` to `initialIntervalSeconds`, so playback delay restarted from the default and had to learn the server's tick rate again; it now keeps the learned interval, and only `reset()` forgets it. `inputMode = TimelineInputMode.Clamp` makes `advance`, `observe` and `hold` absorb a negative or non-finite time or delta instead of throwing, counting each in `clampedInputs`; the default, `TimelineInputMode.Reject`, still throws. Existing signatures are unchanged.
