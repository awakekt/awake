- **Two build plugins generate typed string keys and a version stamp for any project.** `com.awakekt.awake.plugin.string-keys` turns a flat or nested `en.json` into a Kotlin `object` of typed keys (`Strings.menu.start`) with KotlinPoet, failing the build on invalid, duplicate or colliding keys; `com.awakekt.awake.plugin.version-stamp` writes `VERSION` and `COMMIT` constants from a `X.Y.Z`, `-beta.N` or `-rc.N` version and the short git sha, `unknown` outside git. Both add their output to `commonMain` and need no runtime dependency on Awake.
