- **Declarative canvas content: `canvasContent` and its element functions (#1391).** `canvasContent(world, root, state) { s -> … }` declares canvas elements as a function of a `StateFlow` or a `Store`, with `panel`, `text`, `image`, `bar`, `button` and `element`, each a thin wrapper over the prefab builder's `CanvasElementScope` settings. `if`, `forEach` and `key` add, remove and reorder elements as the state changes, and a keyed item keeps its entity. The new `CanvasContentSystem`, part of the scene runtime's infrastructure systems, recomposes a block only on a frame where its state holds a new value, and a pass writes only the settings that changed. `canvasContent(world, root) { … }` with `CanvasContent.recompose()` serves other state sources.
