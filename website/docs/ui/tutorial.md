# UI tutorials and samples

Start with [Install and first app](../getting-started.md), then choose the UI runtime and one
component family. The [UI overview](index.md) explains the separation between neutral layout and
visual policy.

## Available now

1. Add the [Compose runtime](compose.md).
2. Choose [Shadcn](shadcn.md), [Material 3](material3.md), or a headless composition.
3. Follow the [theming guide](../guides/theming.md).
4. Use the [Button tutorial](../guides/components/button.md), which includes a compiler-checked
   source excerpt and a reviewed rendered capture.

The button page is the first stable UI sample. More component pages will be added from showcase
fixtures as each example gains semantic and visual validation; this avoids turning the module
README or a screenshot-only demo into an unverified API guide.
