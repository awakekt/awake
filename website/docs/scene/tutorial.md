# Scene tutorials and samples

Use the scene path after the [core and ECS foundations](../core/tutorial.md). Dependencies stay in
the shared [install and first application guide](../getting-started.md); this section explains how
to compose those capabilities into a scene.

## Recommended path

1. [Author entities and components](authoring.md).
2. [Render a scene](rendering.md) with cameras, lights, and mesh components.
3. Add [navigation](navigation.md), [AI](ai.md), or a streamed [world](world.md) when the game
   needs those systems.

There is not yet one end-to-end scene sample that can be kept compiler-verified across every
backend. The existing pages are the supported focused guides; a full walkthrough will be added
from the engine showcase once its setup can be reduced without hiding lifecycle details.
