# Physics Editor

The Physics Editor provides tooling and diagnostics for Jolt-backed simulation.

## Capabilities

- **Debug Drawing**: Overlay wireframe collision shapes (boxes, spheres, capsules, and heightfields) in the viewport.
- **Body Inspection**: View body types (Static, Dynamic, Kinematic), mass, linear/angular damping, and velocities.
- **Layer Matrix**: Configure and test collision layer masks and interaction rules interactively.
