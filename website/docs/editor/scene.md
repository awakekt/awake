# Scene Editor

The Scene Editor panel manages entities, components, and hierarchies within the active scene.

## Capabilities

- **Entity Outliner**: Tree hierarchy view of all scene entities with filtering and multi-selection.
- **Inspector**: Dynamic property editors for attached components (`Transform`, `MeshRenderer`, `Light`, `Camera`, `Collider`).
- **Gizmos & Manipulation**: 3D translation, rotation, and scaling gizmos rendered directly into the viewport.
- **Prefab Support**: Instantiate, modify, and save scene prefabs.
