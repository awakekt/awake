# Render Editor & Diagnostics

The Render Editor panel provides real-time GPU pipeline and framebuffer diagnostics.

## Capabilities

- **Framebuffer Debugger**: Live display of individual color attachments, shadow maps, and depth buffers.
- **Pass Execution Timeline**: Sequence and duration inspection for offscreen passes, main color passes, and post-processing.
- **Shader Hot-Reloading**: Real-time compilation and reloading of SPIR-V and WGSL shaders.
