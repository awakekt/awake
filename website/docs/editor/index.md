# Awake Editor Suite

The Awake Editor Suite provides visual editing and inspection capabilities designed for rapid iteration.

## Architecture

The editor suite is composed of decoupled modular panels hosted inside Awake Studio:

- **Scene Editor**: Hierarchy manipulation, component inspection, transform gizmos, and prefab instantiation.
- **Physics Editor**: Collider visualization, rigid body tuning, collision layer filtering, and raycast testing.
- **AI Editor**: Behavior tree visual debugging, state machine visualization, and blackboard inspection.
- **Render Editor**: Framebuffer debugging, render pass inspection, and shader parameter tweaking.
