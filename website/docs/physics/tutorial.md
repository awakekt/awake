# Physics tutorials and samples

Install the base application first using the [shared setup guide](../getting-started.md), then
read the [backend-neutral physics overview](api.md) before selecting [Jolt](jolt.md).

## Planned first sample

The first physics walkthrough will create a world, add a static floor and dynamic body, advance a
fixed step, and synchronize the result back to scene transforms. It will be sourced from the
existing engine showcase tests so the example remains aligned with the implementation.

That end-to-end sample is not published yet. Until it is ready, use the API and Jolt pages for the
supported contracts and lifecycle rules rather than treating a README fragment as a complete
integration guide.
