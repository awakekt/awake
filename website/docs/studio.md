# Awake Studio

Awake Studio is the visual IDE and authoring environment for Awake Engine, powered by Compose Multiplatform and the Awake Shadcn design system.

## Features

- **Interactive 3D Viewport**: Hardware-accelerated Vulkan and WebGPU rendering with camera controls, orbit/fly navigation, and entity picking.
- **Dockable Panel Architecture**: Resizable docking layout featuring scene hierarchy, entity inspector, asset browser, and console.
- **Frame & Render Diagnostics**: Real-time FPS monitoring, GPU pass inspection, framebuffer debuggers, and performance counters.
- **Asset Pipeline**: Live glTF 2.0 previewing, shader reloading, and material editing.

## Awake Core vs Awake Pro

Awake Engine's runtime, ECS, Vulkan/WebGPU backends, math libraries, and physics integrations are 100% free and open-source in this repository (`awakekt/awake`). Visual editor panels, advanced world-streaming authoring tools, and commercial studio plugins reside in the Awake Pro suite (`awake-pro`).
