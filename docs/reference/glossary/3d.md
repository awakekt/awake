# 3D rendering glossary

Scene rendering terms. See [2d.md](2d.md) for the UI pass and
[render-extensibility.md](../render-extensibility.md) for the rule several of these serve.

## The distinctions that cost time

| Term | Plain meaning | In Awake |
|---|---|---|
| **capability** | Something the hardware can do, that an app supplies content to. | `DepthTarget`, `DepthOnlyPipeline`, the UI pass, debug lines. Lives in a backend. |
| **content** | The thing being drawn. Answers "what is on screen", which is the app's question. | A skybox, a shadow, fog. Never named in a backend — see `verifyBackendLayering`. |
| **declaration** | Saying *what* an app renders with, independent of any GPU. | `RenderPlan`, `ScenePipeline`, `PipelineSpec`. Duplicating one is a defect. |
| **resolution** | Turning a declaration into real GPU objects, against a real device. | Each engine's `Renderer(...)` construction. Duplicating one is the job — there is one per backend, correctly. |

## Module placement

| Term | Plain meaning | In Awake |
|---|---|---|
| **render contract** | The stable vocabulary a backend and its callers agree on. | `render:contract`: interfaces, data shapes, resource handles and layout vocabulary. It contains no driver calls, filesystem output or test helpers. |
| **render passes** | The shared decisions that turn render inputs into ordered work. | `render:passes`: scene/general feature bodies, preparation, batching and packing algorithms. It has no Vulkan/WebGPU types. |
| **2D render passes** | The shared part of turning 2D primitives into GPU work. | `render:passes2d`: coalescing and mesh-upload/recording ports. It is **not** a UI widget or layout module. |
| **render testing** | Portable diagnostics around a real renderer. | `render:testing`: `PixelMap`, `FrameCapture`, assertions and platform-specific diagnostic writers. A backend fixture may use it in tests, but it is not production renderer API. |
| **backend** | The final translation from shared work to a graphics API. | `backend:vulkan` / `backend:webgpu`: handles, allocation, synchronization and command encoding. It does not decide what a scene, UI, or game feature means. |

## Drawing

| Term | Plain meaning | In Awake |
|---|---|---|
| **draw call** | One request to draw one thing. | `DrawCall` — a mesh, a material, a model matrix, optional per-instance data. |
| **`draw`** | Render the scene and **present** the frame. | `Renderer.draw(camera, drawCalls, light)`. The only call that acquires, records, submits and presents a swapchain frame. |
| **`presentWithoutScene`** | Present a frame with no geometry in it. | For a UI-only app. `drawUi` alone stages primitives but never presents, so without this the window shows its OS-default backing. |
| **prepared draw** | A draw call with every GPU handle already resolved, ready to record. | `PreparedDraw` (shared), `PreparedDrawCall` (Vulkan). What shared feature code iterates. |
| **pass** | A bracketed span of recording with one set of attachments. | Scene pass, UI pass, and the depth pre-pass, which owns its own. |
| **feature** | One unit of work inside a pass, in paint order. | `RenderFeature`, held in an ordered list. Adding one must not mean editing the frame loop. |

## Pipelines and shaders

| Term | Plain meaning | In Awake |
|---|---|---|
| **pipeline** | Compiled GPU state: shaders, vertex layout, blend, depth, cull. | `RenderPipeline`. Compiled once at load, never mid-frame — a miss costs 1–50ms against a 16ms budget. |
| **`PipelineSpec`** | The backend-neutral *description* a pipeline is compiled from. | Value-equal, so registering the same one twice compiles it once. |
| **`PipelineKey`** | What a pipeline is *for*, so a draw can find it. | `Primary`, `Format(...)`, `Instanced`, `SkinnedInstanced`, `Particle`. |
| **`PipelineVariant`** | A named preset of the state flags, not four loose booleans. | `Opaque`, `Instanced`, `AlphaBlendedParticle`, `Background`. |
| **`ShaderSet`** | One shader named once, with a half per backend. | Vulkan wants a SPIR-V `.vert.spv`/`.frag.spv` pair; WebGPU wants one `.wgsl`. The engine picks the half. |
| **`VertexFormat`** | The attribute layout of a mesh's vertices. | Also the **join key** from mesh to pipeline. `VertexFormat.None` means the shader generates its own vertices. |

## Uniforms

| Term | Plain meaning | In Awake |
|---|---|---|
| **uniform** | A value constant across one draw, read by the shader. | Written into a per-draw buffer, bound as a descriptor set / bind group. |
| **`UniformLayout`** | The field list of a shader's `Uniforms` struct, in order. | Sizes the buffer *and* orders the writes. Order is load-bearing. |
| **`UniformWriter`** | Writes a block, checking each field against the layout. | Matches by **identity**, so a wrong-but-same-shaped field is a failure, not a silent mis-write. |
| **std140 padding** | The alignment rule that makes a `vec3` occupy four floats. | Why light and colour fields are declared `Vec4` and carry a scalar in the unused slot. |

## Depth and shadows

| Term | Plain meaning | In Awake |
|---|---|---|
| **depth pre-pass** | Rendering the scene depth-only, before the scene pass. | `DepthPrePassFeature`, into a `DepthTarget`. Knows nothing about *why* — shadow mapping is one use. |
| **shadow map** | A depth target rendered from a light's point of view. | The light's own `viewProjection`, supplied by `RenderSystem` — a backend never derives it. |
| **depth bias** | A small offset applied when comparing depths, to stop self-shadowing. | Scaled by `directionalShadowTexelDepthScale` so its constants can be written in texels. |

## Backend

| Term | Plain meaning | In Awake |
|---|---|---|
| **backend** | The driver layer: Vulkan or WebGPU. | Knows pipelines, buffers, textures, samplers, command recording. Nothing else. |
| **swapchain** | The queue of images the window presents from. | Vulkan runs 2 frames in flight; WebGPU 1, since the browser owns its swapchain. |
| **clip space** | The coordinate space a projection matrix outputs into. | Differs between the two APIs, which is why `ClipSpace` is a parameter rather than a constant. |
| **`RenderCapabilities`** | What a backend can actually run, declared by that backend. | A plan it cannot fully run is **narrowed and reported**, never rejected — and never silently dropped. |
