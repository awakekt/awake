# 2D rendering glossary

UI rendering terms — how a widget becomes pixels. See [3d.md](3d.md) for the scene pass and
[ui-testing.md](ui-testing.md) for test vocabulary.

`:awake:compose:*` is replacing `:awake:ui:*`; entries below marked **(compose engine)** are the
newer spelling, and both are current while that migration runs.

## The frame

| Term | Plain meaning | In Awake |
|---|---|---|
| **primitive** | The lowest-level thing the UI renderer draws. | `UiDrawPrimitive`: `Quad`, `GradientQuad`, `RoundedQuad`, `Glyph`, `FilledPath`, `StrokedPath`, `ShadowQuad`. A widget becomes some of these. |
| **`drawUi`** | Stage this frame's primitives into pooled GPU meshes. | Does **not** present. A frame that only calls `drawUi` never reaches the screen — see `presentWithoutScene` in [3d.md](3d.md). |
| **frame lifecycle** | Begin, author, finish. | `UiContext.beginFrame` → widget calls → `finishFrame`, which returns the primitives and the frame's effects (cursor, keyboard request). |
| **paint order** | The order things are drawn, so later covers earlier. | Deliberately **not** sorted by pipeline or material. Batching reorders, and reordering overlapping UI changes what you see. |
| **coalescing** | Merging adjacent primitives that share state into one draw. | Preserves order — it only merges *runs*, never reorders them. |
| **headless rasterizer** | The deterministic CPU renderer used by previews and image assertions. | `UiRasterizer` consumes the same primitive list as the GPU route. It is excellent for layout/debug captures, but is not proof of GPU paint fidelity. |
| **offscreen texture capture** | Rendering to a GPU texture instead of a window, then reading its pixels. | The backend-fidelity lane: use it when a question concerns GPU blending, shaders, frame pacing, or the real rendering pipeline. |

## Vectors and edges

| Term | Plain meaning | In Awake |
|---|---|---|
| **vector graphic** | An image described by paths and drawing rules rather than a bitmap. | `ImageVector` contains an SVG-sized viewport plus `VectorPath` entries. Icon sources are generated from the official SVG; their coordinates are never hand-authored. |
| **filled path** | A closed outline whose interior is painted. | `FilledPath` uses `DrawPath.tessellateFillAa` so its boundary carries an anti-aliased fringe. SVG paths without an explicit fill inherit the icon tint (`currentColor`). |
| **stroked path** | A centreline painted with a width, caps, and joins. | `StrokedPath` carries `DrawStroke`; before rasterization it is expanded into one filled outline, so round caps and joins remain continuous at icon sizes. |
| **stroke cap** | The shape at the end of an open stroke. | `Butt`, `Round`, or `Square` in `DrawStroke`. Lucide defaults to `Round`; treating it as a rectangular segment makes checks and chevrons visibly rough. |
| **stroke join** | The connection where two stroke segments meet. | `Miter`, `Round`, or `Bevel` in `DrawStroke`. It is applied while creating the continuous outline, not approximated by overlapping quads. |
| **tessellation** | Converting a path into triangles the renderer can draw. | `tessellateFill`, `tessellateFillAa`, and `tessellateStroke` live in `:awake:core:graphics2d`. It is shared rendering infrastructure, not recipe policy. |
| **anti-aliased fringe** | A narrow partially-transparent band around geometry that smooths a pixel edge. | `tessellateFillAa` generates it for filled and expanded stroke paths. A missing fringe is a rendering defect, not a reason to distort icon coordinates. |

## Layout

| Term | Plain meaning | In Awake |
|---|---|---|
| **constraints** | The min/max size a parent offers a child. | `UiBoxConstraints`, and `Constraints` in the compose engine. A child answers with a size inside them. |
| **measure** | Work out how big something wants to be. | Separate from placement: measuring may happen more than once per frame. |
| **trial measure** | A speculative measure whose result may be thrown away. | Why work inside a layout lambda can run several times per frame — the cost multiplies, so nothing expensive belongs there. |
| **place** | Decide where a measured child sits. | Runs once per frame per child, unlike measure. |
| **`Modifier`** | A chain describing size, padding, background and behaviour. | Order matters: `.padding().background()` and `.background().padding()` differ. |
| **`Dp`** | Density-independent pixel — a size that means the same physically at any DPI. | Authored sizes are `Dp`; only the renderer works in raw pixels. Hardcoding pixels breaks on a 2× display. |
| **scope** | The receiver that says which layout you are inside. | `ColumnScope`, `RowScope`. Getting the receiver wrong binds a nested call to the wrong parent — silently, with no error. |

## Style and semantics

| Term | Plain meaning | In Awake |
|---|---|---|
| **`Style`** | Background, border, radius, padding and colour for one component. | A **receiver** lambda: `Style { background(x); hovered { background(y) } }` — not a parameter. |
| **state rule** | A style branch that applies only in a given state. | `hovered { }`, applied against the same scope, so a component's states live in one declaration. |
| **semantics** | The meaning of the UI, for tests and accessibility. | A tree of nodes with ids, roles, labels, bounds. Not pixels — a test asserting semantics is not asserting appearance. |
| **theme / token** | The named values a design system resolves colours and sizes from. | A component reads tokens; it does not hardcode a colour. |
| **content color** | The colour inherited by text and `currentColor` icons inside a visual container. | `LocalTextStyle.color` provides this existing Compose-shaped cascade. A button supplies its variant foreground so arbitrary slotted text and `shadcnIcon` match the source CSS cascade. |
| **Compose component name** | The public name of a Compose-facing visual function. | PascalCase (`ShadcnButton`, `ShadcnSelect`). Lowercase `shadcn*` functions are deprecated compatibility delegates, not parallel recipes. |
| **content slot** | A caller-owned visible region supplied as a lambda. | Named `context(Composer) () -> Unit` slots keep layout ownership and modifier order with the caller; convenience label/icon overloads delegate to the same slot path. |
| **Tailwind utility** | A source class that maps a role to a design token or layout rule. | `gap-2`/`px-3` resolve through generated `Tw.Spacing` values; the class-to-role translation is checked against the pinned `.tsx` source. |
| **icon registry** | The replaceable path from source glyph data to a recipe default. | `HeroIcons` owns vector data, `UiIcons` exposes headless defaults, and `ShadcnIcons` owns design-system-overridable defaults. |
| **cursor oracle** | A deterministic assertion for text-input caret behavior. | Tests assert `TextFieldState.cursor`, text, focus, and edit-command results across frames; cursor-blink pixels are not a screenshot oracle. |
| **core issue** | A tracked mismatch that the recipe, token, fixture, or comparison tool cannot express or fix. | Record it in `docs/reference/ui-parity-core-issues.md` only after evidence isolates a missing engine capability. Ordinary color, padding, icon, hit-target, or behavior bugs are fixed immediately. |
| **phase discipline** | Reading a value in the frame phase that consumes it, rather than capturing it at composition. | A field's text is read by `TextMeasurePolicy` during measure and by `drawBehind` during paint. Capturing it at composition leaves the glyphs stale, since nothing re-runs the composable on a keystroke. |

## Reference and parity evidence

| Term | Plain meaning | In Awake |
|---|---|---|
| **reference capture** | Browser output from the pinned upstream component, including DOM measurements and a PNG. | `tools/shadcn/capture_shadcn_local.py` produces the source artifact. A third-party Compose port or an Awake golden is never the source reference. |
| **semantic capture** | A JSON record of the retained UI tree's stable IDs, roles, labels, states, and bounds. | `captureSemantics()` supplies geometry and interaction evidence. It does not establish pixel fidelity. |
| **parity scope** | One independently-measured kind of similarity. | Structural covers geometry/padding/spacing/relationships; surface covers style fields. Raster, typography, shadows, colors, behavior, and motion are reported separately so a single misleading percentage cannot hide missing evidence. |
| **structural parity score** | The percent of measured structural checks that pass, accompanied by coverage. | It reaches 100% only when every required structural check is measured and passes. Unmeasured checks make the score unavailable, not artificially perfect. |
| **surface parity score** | The percent of measured style checks that pass, accompanied by coverage. | It concerns recipe-resolvable fields such as border, radius, and resolved color roles; it deliberately excludes glyph rasterization and shadow kernels. |
| **diff / heatmap** | An image that highlights per-pixel differences between an Awake and reference crop. | A diagnostic review artifact. A low mismatch percentage is not a pass until geometry matches and the remaining pattern is explained. |
| **core-issue tracker** | Backlog for a mismatch that a component recipe, token, fixture, or tool cannot express or fix. | `docs/reference/ui-parity-core-issues.md`. Normal padding, color, icon, hit-target, or interaction bugs are fixed immediately and never entered here. |

## Text

| Term | Plain meaning | In Awake |
|---|---|---|
| **glyph** | One rendered character. | A `Glyph` primitive with atlas UVs — not a string. |
| **atlas** | One texture holding many glyphs. | Text draws as quads sampling it, which is why one font swap invalidates cached text. |
| **ink vs quad metrics** | The bounds of the marks, versus the bounds of the cell drawn. | They differ, and mixing them up shifts text by a fraction of a pixel — see the glyph UV work in `docs/tasks`. |
