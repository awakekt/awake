Start the authoritative server first: ./gradlew :samples:net-demo:desktopRun --args="server 9540"
Override with ?port=9540&name=browser.

For wss://, run the server with --tls and add &tls=1 here. The demo's certificate is self-signed, and a page cannot ask the browser to trust one: open https://localhost:<port> once and accept the warning first, or issue a locally-trusted certificate with mkcert. A refused certificate looks exactly like a server that is down.
