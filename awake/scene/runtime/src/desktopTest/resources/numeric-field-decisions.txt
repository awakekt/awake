# Decisions about the numeric properties of registered scene components, read by NumericFieldDecisionsTest.
#
# A numeric property needs one of:
#   - a @PropertyRange on it, because the component's validate() already limits it (no line needed);
#   - `free <component>.<property> | <reason>`: it deliberately has no per-property limit;
#   - `undecided <component>.<property>`: its module's batch has not been done yet. This only shrinks.
#
# Nested properties are written with dots (`particle_emitter.spin.maxDegreesPerSecond`); a list of
# objects with `[]` (`particle_emitter.ground.colliders[].x`).
