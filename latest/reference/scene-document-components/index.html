    Scene document components

    Every component id a scene document can hold, with each field's type and default. A test fails when a registered component or field has no row here.

    A component is one entry of a node's components array, named by its component key. For the file around it, see Scene document schema. Types use the value types of the schema page.

    All components

    ambient_light

    Uniform light added to every surface. SceneAmbientLight.

    Field Type Default What it does
    intensity number 0.2 Brightness of the ambient term.
    color color white Ambient color.
    colorR number none Legacy red channel. When colorR, colorG and colorB are all set, they replace color.
    colorG number none Legacy green channel.
    colorB number none Legacy blue channel.

    audio_source

    A sound this node plays: a clip from the project's files, placed at the node for a 3D sound. loadProject reads each clip once, as a 16-bit PCM WAV file; a clip that can't be read or decoded is logged with the node, and that source stays silent while the scene plays on. During play a 3D sound fades with distance from the active camera and pans with its direction. SceneAudioSource.

    Field Type Default What it does
    clip string "unassigned" Project path of the clip's WAV file. "unassigned" is a source with no clip picked yet; nothing is read for it.
    volume number 1 Loudness, 0 for silent, 1 as recorded. Not negative.
    isSpatial3D boolean true Whether it fades with distance and pans with direction.
    maxDistance number 50 The distance a 3D sound fades out at. Above 0.
    autoPlay boolean false Whether it starts as soon as the scene plays.
    loop boolean false Whether it starts again when it ends.

    behavior_tree

    Runs the behaviour tree in a definition file. SceneBehaviorTree. A played project reads and checks the file when it loads, and gives the entity a BehaviorTreeComponent built from it.

    Field Type Default What it does
    asset string required Path of the definition, a BehaviorTreeDefinition as JSON. Must not be blank.
    seed integer or none none Seeds the tree's random nodes. None gives each entity its own.
    enabled boolean true Whether the tree runs.

    blueprint

    Runs a blueprint graph on the entity. SceneBlueprint.

    Field Type Default What it does
    graph string required Path of the graph. Must not be blank.
    variables object of string, number or boolean {} Starting values for the graph's variables, by name.

    camera

    A camera lens. At most one per node. SceneCamera.

    Field Type Default What it does
    eye vector {x: 0, y: 0, z: 5} World-space eye position.
    center vector {x: 0, y: 0, z: 0} World-space point the camera looks at.
    up vector {x: 0, y: 1, z: 0} Up direction.
    fovYDegrees number 60 Vertical field of view in degrees. Between 0 and 180, exclusive.
    near number 0.1 Near clipping distance. Above 0.
    far number 100 Far clipping distance. Above near.
    primary boolean true Whether this camera renders the main view.
    projection perspective · orthographic perspective orthographic keeps things the same size at any distance, as a 2D game wants, and ignores fovYDegrees.
    orthoHalfHeight number about 2.07 Half the vertical world extent an orthographic view covers; the width follows from the aspect ratio. Above 0. Used only when projection is orthographic.
    viewport object none Optional orthographic virtual viewport: positive finite width and height in world units, and scaling (fit, extend, fill, stretch, screen; default fit). Replaces orthoHalfHeight for rendering. Fit centers bars; Extend reveals more world; Fill crops; Stretch scales each axis; Screen uses one world unit per physical framebuffer pixel. Omit for the existing camera framing.

    camera_rig

    How a camera follows or orbits. SceneCameraRig.

    Field Type Default What it does
    mode FirstPerson · ThirdPerson · FreeFly · Cinematic · TopDown ThirdPerson Camera behavior.
    target string none Name of the node to follow.
    distance number 5 Distance from the target.
    minDistance number 2 Closest zoom.
    maxDistance number 20 Farthest zoom.
    pitch number 0 Pitch in radians. Negative looks down.
    yaw number 0 Yaw in radians.
    offset vector {x: 0, y: 1.8, z: 0} Aim point relative to the target, or the pivot when there is none.
    flySpeed number 10 Speed in FreeFly mode. Above 0.

    canvas_controls

    What every on-screen control on the scene's canvas shares. A scene has one, on any node; without one, touch controls show as the host says. SceneCanvasControls, saved from the live CanvasControls.

    Field Type Default What it does
    touchVisibility Host · Auto · Always · Never Host When touchOnly elements show. Host as the host says; Auto once a finger touches the screen, and hidden once a controller, a key or the mouse is used, switching live, as the host says until any is used; Always; Never. A control hidden mid-press lets go of its pointer.
    theme object none How every control looks, slot by slot. preset (MinimalFlat · Glass · Textured · None) is the built-in look it starts from; colors and images are tokens, by name, a slot writes as @name in a colour or an image path, over the preset's own; skin sets slots over the preset's: joystick (base, knob, sprintRing, arrows), button (background, icon, label, cooldown, charges, aimCursor, aimRange, cancelZone) and look (feedback). A slot is a style (as canvas_element.style), a size, circle, frames (images, fps, loop), custom (a composable the host registered by that name), hidden, transitionSeconds, and states by Idle · Pressed · Held · Disabled · CoolingDown · Ready · Aiming · Cancelling, each changing its style, scale, alpha, frames or hidden. A token neither the theme nor its preset has is reported. None draws each control plainly from its own colours. See Game UI.
    playerLayout object {} The layout the scene starts with, before a player's saved one replaces it: every touch control's scale (1) and opacity (1), and controls, each control's own offsetX, offsetY (dp, right and down), scale and opacity by its controlId.
    minTouchSize number 44 The smallest a stick, action button or look area is to a thumb, in dp: one drawn smaller takes a touch up to this size around its centre. 0 takes touches only on what is drawn. Not negative.

    canvas_element

    Screen-space UI drawn over the game. Sizes and offsets are in dp. SceneCanvasElement.

    Field Type Default What it does
    kind Text · Panel · Bar · Button · TextField · Joystick · Image · View · LookArea · Sweep · Stepper Text What the element is. A View shows what a camera sees; a LookArea is a region where a swipe looks and a pinch zooms; a Sweep fills its value of a turn; a Stepper holds a number between minus and plus buttons.
    anchor TopLeft · TopCenter · TopRight · CenterLeft · Center · CenterRight · BottomLeft · BottomCenter · BottomRight TopLeft Screen point the element is placed from.
    offsetX number 16 Horizontal offset from the anchor: inward from a left or right edge, never past it, and right of centre on a centred axis, or left when negative.
    offsetY number 16 Vertical offset from the anchor: inward from a top or bottom edge, never past it, and below centre on a centred axis, or above when negative.
    width number 200 Width. Not negative.
    height number 40 Height. Not negative.
    text string "" A Text element's content, a Button's label, or what is typed into a TextField: typing writes it, and a system writing it replaces the field's content, caret at the end. In a Text element with links true, a [[key&#124;shown words]] span draws "shown words" in style's linkColor and reports key once through consumeLink() when clicked; [[ is reserved and has no escape. Plain text with no span draws unchanged.
    textKey string "" A Text's or Button's words by key, from the project's strings/<locale>.json tables, in the active locale; they change when it does. Empty shows text. A key no table has shows as the key and is logged once. Set on another kind, or with text or bind.text, it is reported. See Localization.
    textArgs object {} Values for textKey's placeholders, by name, such as { "count": "3" }. A bind's textArgs reads one from a field instead. Set without textKey, it is reported.
    fontSize number 18 Text size. Above 0.
    color string "#FFFFFF" Foreground color, #RRGGBB or #RRGGBBAA.
    background string "#00000000" Background color, #RRGGBB or #RRGGBBAA.
    value number 1 A Bar's fill, from 0 to 1.
    order integer 0 Draw order. Lowest draws first.
    visible boolean true Whether the element is drawn.
    action string "" Name of what the element does for the game, such as jump. The game decides what each name means. In a played project, an element naming one of the scene's input actions adds to it, and its presses are used up: a Joystick steers an axis such as move, and a Button holds and presses a button such as jump or run. Any other name is left for the game to read.
    doubleAction string "" What a Button does when double-clicked: two presses within half a second. The second press also fires action. Like action, a name among the scene's input actions is pressed, and any other is left for the game to read with consumeDoublePress().
    touchOnly boolean false Draw only where touch controls are shown.
    safeArea boolean true Keep an anchored element on the canvas itself inside the screen's safe area, clear of a notch, rounded corners, a home indicator or overscan: its anchor and offsets are measured from the safe area's edges and centre. false measures them from the screen's own edges, for a backdrop that reaches under a notch. An element inside another, or one that follows a node, is placed the same either way.
    style object {} How the element looks beyond its colours, as an AwakeKt Compose Style: background, gradient (start, end, horizontal), image, fillImage, fillImageMode, cornerRadius, borderWidth, borderColor, shadow (color, offsetX, offsetY, blur, spread), textColor, textShadow (color, offsetX, offsetY), textOutline (color, width), alpha, rotation, linkColor, and hovered, pressed and disabled states for a Button. image is an Image's picture, a frame, or a Bar's track; fillImage is a Bar's fill, cut at value or, with fillImageMode Squeeze, drawn at the filled width with both end caps kept, or with fillImageMode Sweep, revealed clockwise from 12 o'clock over the Bar's whole box, like a cooldown overlay -- fillImage is optional there, and the colour fill sweeps on its own. Each image is a CanvasImage: path, a region (regionX, regionY, regionWidth, regionHeight), slice insets (sliceLeft, sliceTop, sliceRight, sliceBottom), repeatEdges, repeatCenter, tint and pixelated. rotation turns the element's image, background and content, children included, clockwise about its own centre in degrees; hit-testing still uses the unrotated box. linkColor colours a Text's [[key&#124;shown words]] spans; unset draws them in a default blue. See Game UI.
    textAlign TopLeft · TopCenter · TopRight · CenterLeft · Center · CenterRight · BottomLeft · BottomCenter · BottomRight none Where a Text's or Button's text sits in the element. None keeps the kind's own: top-left for a Text, centred for a Button.
    follow string "" The name of a node the element follows on screen. Its anchor point stands on the node's projected position, nudged inward by its offsets, and it hides when the node is behind the camera or missing.
    followOffset vector {x: 0, y: 0, z: 0} World-space offset from the followed node, such as above its head.
    followBounds boolean false Cover the screen rectangle of the followed node's meshes instead of standing at its point. Its children anchor to that box's edges.
    followRules object none How a follower behaves with many on screen. cullOffScreen (true) leaves it out while its box is wholly off the screen; maxDistance (0, none) hides it farther than that from the camera, in world units; occlusion (false) hides it while a physics body other than the followed node's own stands between the camera and the point, within the budget of the scene's canvas_follow_occlusion. group ("") is the canvas_follow_limit it counts against, and priority (0) ranks it there. scale and fade are curves of its size and opacity by distance: points of at (a distance) and value, straight between them and held past the ends; it is left out when faded or scaled to nothing. pinToEdge (false) holds it to the screen's edge, edgeMargin dp in, on the side its target lies while that is off screen or behind the camera, instead of hiding it. None culls it off screen and hides it behind the camera. Set on an element that follows nothing, it is reported. See Game UI.
    followArrow boolean false Inside a follower, this element is the arrow of one pinned to the edge: drawn only while its parent is pinned, centred on its parent's edge toward the target and turned to point there, its picture pointing right before it turns; its style.rotation adds to the turn. Set on an element that follows a node itself, it is reported.
    followOutset number 0 With followBounds, how far the box reaches past the node's rectangle on each side, in dp, so corner children sit outside the node. Negative pulls it in, never below nothing.
    layout object none Lay the element's children out in rows or columns instead of anchoring each: direction (Row · RowReverse · Column · ColumnReverse), wrap, gap, padding, justify (Start · Center · End · SpaceBetween · SpaceAround · SpaceEvenly) and align (Start · Center · End · Stretch). A laid-out child keeps its width and height and ignores its anchor and offsets. See Game UI.
    grow number 0 In a parent with a layout, this element's share of its line's leftover space. Not negative.
    bind object none Game state the element shows without code. node names a node; value is a component.field for a Bar's fill, divided by max (a field or a number); text fills each {component.field}, or {component.field:n0} with a number format, in a Text's or Button's words. textArgs maps a textKey's argument names to component.fields, read each frame. For an action button, cooldown (divided by cooldownMax, a field or a number), charges and enabled read its live cooldown, uses left and whether it can be pressed. See Game UI.
    wheel boolean false Take the mouse wheel while the pointer is over this element or its children, instead of leaving it for gameplay. The innermost such element under the pointer takes it; read it back with consumeWheel().
    draggable boolean false Can be picked up: a ghost of it follows the pointer while dragging is true. A plain click still fires if the pointer never moves far enough to start a drag. Releasing on a dropTarget reports it there through dropped; releasing elsewhere reports it on this element's droppedOutside, a point in canvas units. Both are properties read once.
    dropTarget boolean false Receives a draggable element released over it, read back through dropped.
    camera string "" A View's camera: the name of a node with a camera, whose picture fills the element's box, opaque, at its size in pixels, inside its style.cornerRadius and under its children. Give that camera primary: false so it does not become the main view. With no such node, or no renderer, the element draws only its style.
    links boolean true Whether a Text element's [[key&#124;shown words]] spans draw as links. false draws [[ and ]] as typed and no click reports a key -- set it for text the game cannot trust, such as player chat.
    mask string "" A TextField's password mask: one character, such as *, drawn for each typed one. text keeps what was typed; copy and cut yield nothing, and accessibility services and the platform keyboard treat the field as a password. Empty draws the text as typed, so clearing it at runtime shows the password. Longer than one character, or set on another kind, is reported.
    maxLength integer 0 The most a TextField lets the player type, counted in maxLengthUnit; 0 for no limit. Typing, pasting and an IME stop at the limit, and never inside a character: an emoji, a flag or a letter with its accents goes in whole or not at all. A system writing text is not limited. Not negative; set on another kind, it is reported.
    maxLengthUnit Graphemes · CodePoints · Utf8Bytes Graphemes What maxLength counts. Graphemes are the characters a player sees, so a family emoji is one. Count CodePoints or Utf8Bytes to match the limit a server stores a line in, so a line the field accepts is never refused or cut there.
    font string "" The font a Text's, TextField's or Button's words draw in. A path ending in .ttf or .otf, any case, names a TrueType or OpenType file from the project's root, loaded once with the scene; one that cannot be read or is not a font is logged once and draws in the default font. Any other value names a built-in family: default (Roboto) or bitmap (a fixed-pitch pixel font). Empty draws in the default font. Another name, or a path with another extension, is reported. See Game UI.
    pressable boolean false Makes an Image or Panel take a tap as a Button does: consumePress() and consumePressAt() report it, and what is under the element doesn't get it. false leaves it watching the pointer only, so a tap passes through. A Button is always pressable; set on any other kind, it is reported.
    button object none Makes a Button an action button. trigger (Tap): fire action on a Tap released over it, or the moment it goes Down. Held longPressSeconds (0.5), it presses longPressAction, and the release is then not a tap. Let go anywhere, it presses releaseAction. Its live cooldown sweeps a shade over it and its charges show in a badge, set from code or bind; while cooling with no charge left it takes no press unless blockWhileCooling (true) is false. cooldownSeconds (0) gives it a cooldown of its own, run from 1 to 0 over that many seconds each time it fires; set with bind.cooldown, it is reported. aim makes it drag to aim and fire on release, wherever the thumb is: mode (Direction · Ground), radius (0, 120 dp), deadZone (0.2), a cancel zone (anchor, offsetX, offsetY, width, height) where letting go cancels, the axis aimAction pushed with the aim, and lockTarget, which asks the element's code-set aimLock for a target. Each action button follows only the pointer that landed on it first. Set on another kind, it is reported. See Game UI.
    enabled boolean true Whether a Button can be pressed. A disabled one takes no press, keeps it from what is under it, and draws in style.disabled, or dimmed. A bind.enabled field sets it each frame instead.
    look object none How a LookArea turns a swipe into a look and a pinch into a zoom: sensitivity (1), invertX, invertY, pinchZoom (true), zoomSensitivity (1), turnsCamera (true), which turns and zooms the active camera rig in a played project, and the axis zoomAction the pinch is pushed to as ln of its factor. The element's action names an axis action the swipe is pushed to. Set on another kind, it is reported.
    cluster object none Places the element's children as a button cluster instead of a layout: the first on a pivot (pivotX, pivotY, 1, shares of the element) unless primaryAtPivot is false, and the rest radius (96) dp from it, from startAngle (180) and spacing (45) degrees apart, clockwise from the right. Set with layout, it is reported.
    skin object none How this control looks, slot by slot, over the scene's canvas_controls theme: the same joystick, button and look slots as a theme's skin. A colour or image path written @name is the theme's token.
    controlId string "" The name a player's saved layout knows this control by, such as move, so canvas_controls.playerLayout.controls can move, scale and fade it.
    elementId string "" The stable id code finds this element by, such as health-bar: it survives a rename and repeats in each instance of a prefab, so code looks it up under one instance's root with World.findCanvasElement. Letters, digits, _, . and -, starting with a letter, digit or _; unique within a prefab. See Game UI.
    bar object none How a Bar draws as a progress bar: direction (LeftToRight · RightToLeft · BottomToTop · TopToBottom · Radial), a radial ring's thickness, a track colour, a trailColor fill that trails a drop by trailDelay seconds (0.5) and drains at trailSpeed (1.5), segments blocks segmentGap (2) dp apart, ticks in tickColor, and a label. Set on another kind, it is reported. See Game UI.

    keyframe_animation

    Loops keyframe tracks on its node: position, rotation, scale and material alpha. SceneKeyframeAnimation.

    alpha list of number keys [] The material's base colour alpha over the loop.

    Key

    Each key is {"time": 0.5, "value": ...}: time in seconds from the start of the loop, between 0 and duration, and in order within its track; value a vector for position, rotation and scale, a number for alpha.

    horizonColorR number none Legacy channel. When all three horizonColor* channels are set, they replace horizonColor.
    horizonColorG number none Legacy channel.
    horizonColorB number none Legacy channel.
    zenithColorR number none Legacy channel. When all three zenithColor* channels are set, they replace zenithColor.
    zenithColorG number none Legacy channel.
    zenithColorB number none Legacy channel.
    cubemapPath string none Cubemap asset path, for Cubemap.
    exposure number 1 Cubemap brightness, for Cubemap.

    spin_control

    Rotates the entity around Y. SceneSpinControl.

    Field Type Default What it does
    radians number 0 Starting angle in radians.
    speed number 1 Rotation speed multiplier. Not negative.

    sprite

    A flat image drawn at the node's Transform, with no lighting: one cell of a frame sheet. Its size is the cell's pixel size divided by pixelsPerUnit, so under an orthographic camera it keeps its size however the image is scaled. SceneSprite.

    A project played with runProject reads the image from the project's files the first time the sprite is drawn. Until it has loaded, the sprite is not drawn; an image that can't be read draws nothing and is logged once. An image whose size doesn't divide into columns by rows whole-pixel cells is not drawn either, and is logged once. A host that changes the file has the scene's asset library forgetTexture it (or requestForgetTexture it from another thread), and the next frame reads it again.

    Field Type Default What it does
    texture string required A project image file the sprite shows. Not blank.
    columns integer 1 Frame-sheet columns. At least 1.
    rows integer 1 Frame-sheet rows. At least 1.
    frame integer 0 The cell shown, counted from 0 in reading order from the top left. Within the sheet.
    pixelsPerUnit number 100 Image pixels that make one scene unit. Finite and above 0.
    flipX boolean false Mirrors the sprite left to right.
    flipY boolean false Mirrors the sprite top to bottom.
    tint color white Multiplied into the image's colour and alpha.
    sortOrder integer 0 Within its sortingLayer, a higher order draws over a lower one; a tie draws by depth from the camera.
    pivot object (x, y) {"x": 0.5, "y": 0.5} The point of the frame placed at the node, which the sprite turns and scales about, as a fraction of the frame from its bottom left: the default is its centre, {"x": 0.5, "y": 0} the middle of its bottom edge. It holds for every frame, and a flipped sprite mirrors about it. Finite; outside 0 to 1 places it outside the frame.
    sortingLayer string "Default" The project's sorting layer it draws on: a later layer in the manifest's sortingLayers draws over an earlier one whatever their sortOrder. A name the list leaves out draws on Default, and is a warning when the project loads. Not blank.
    ## state_machine

    Runs the state machine in a definition file. SceneStateMachine. A played project reads and checks the file when it loads, and gives the entity an AiStateMachineComponent built from it.

    Field Type Default What it does
    asset string required Path of the definition, a StateMachineDefinition as JSON. Must not be blank.
    seed integer or none none Seeds the machine's random nodes. None gives each entity its own.
    enabled boolean true Whether the machine runs.

    tilemap

    A finite orthogonal atlas layer. The node's origin is its top left, with +X right and -Y down. The runtime uploads one mesh per non-empty chunk, draws visible chunks through the sprite pipeline, and rebuilds only edited chunks. Its atlas image loads as a sprite's does. SceneTilemap.

    Field Type Default What it does
    texture string required Named atlas image; must not be blank.
    width integer required Map columns. At least 1.
    height integer required Map rows. At least 1.
    tiles list of integers required Exactly width times height frames in row order; -1 is empty.
    columns integer 1 Atlas columns. At least 1.
    rows integer 1 Atlas rows. At least 1.
    pixelsPerUnit number 100 Pixels per local world unit. Finite and above 0.
    chunkSize integer 16 Cells per chunk edge. At least 1; edge chunks may be smaller.
    tint color white Whole-layer straight-alpha multiplier.
    sortOrder integer 0 Within its sortingLayer, higher order draws after lower-order tilemaps and sprites.
    sortingLayer string "Default" The project's sorting layer it draws on, shared with sprites. Not blank.

    sprite_clips

    Named animation runs for the sprite on the same node. Sheet dimensions come from that sprite; every run must fit its atlas. SceneSpriteClips.

    The standard scene runtime advances SpriteClipSystem before rendering, and sceneSystemsFor includes it for a scene with sprite_clips, so an editor's Play advances them. A custom host runs it once per simulation frame. SpriteClips.play("hit") changes the run; repeated requests preserve time unless restart = true. speed = 0 pauses this entity, and isFinished reports one-shot completion. An empty library leaves the sprite's manually selected frame alone. Export saves the selected clip name, while playback time and speed remain transient runtime state.

    Field Type Default What it does
    clips object of runs {} Runs by name. Names must not be empty.
    clip string the first listed Initial run; must name a run in clips.

    Sprite run

    Each entry in clips is a SceneSpriteClip:

    Field Type Default What it does
    firstFrame integer 0 First cell, counted from the top left across rows. Not negative.
    frameCount integer 1 Cells in the run; at least one and the whole run must fit the sprite.
    framesPerSecond number 0 Authored playback rate. Finite and not negative; zero holds the first cell.
    loop boolean true Repeat the run. False plays once and holds its last cell.

    Importing sprite-sheet metadata

    SpriteGenManifest.decode(manifestText) from com.awakekt.awake.asset:sprite imports a sprite-gen component-row manifest. It returns the image reference, regular grid and named clips. Resolve the image through your asset loader and verify its decoded size with sheet.requireImageSize(width, height).

    Before instantiation, call authored.withSpriteSheets(mapOf("hero" to sheet)), importing the extension from com.awakekt.awake.scene.scene2d. Keys match each sprite's authored texture. This fills in atlas dimensions and runs on nested matching nodes, retains clip selection and styling, and lets local runs override imported names. The result saves as ordinary scene components.

    Runs must contain contiguous, untrimmed cells on one row. Uniform durations_ms overrides fps; without durations, fps is required. Packed atlases, reordered cells and variable frame durations are unsupported and rejected with IllegalArgumentException.

    static_transform

    Marks a node that never moves, such as a placed prop. SceneStaticTransform, no fields.

    TransformSystem builds the node's world matrix once and then skips it, so a level of thousands of props costs almost nothing per frame. The node's parent must not move either: a static node does not follow a parent that moves. An editor that moves static nodes uses TransformSystem(skipsStatic = false).

    { "component": "static_transform" }

    tag

    What the entity is to gameplay, by role, such as enemy or pickup. It becomes the entity's Tags (awake:ecs), which code finds with world.withTag("enemy") and tests with world.hasTag(entity, "enemy"). A prefab's tags ride on its root entity; tags on the node that links the prefab tag that node. SceneTag.

    Field Type Default What it does
    tags array of strings [] The node's tags, any number of them. Each is letters, digits, _, . and -, starting with a letter, digit or _. A project can list its tags in the manifest's tags; a scene tag the list leaves out is a warning when the project loads.

    texture_animation

    Plays the entity's texture as a frame sheet and scrolls it. The textured shader applies it to every texture of the entity's material; with no pbr_material it plays with glTF's default factors. SceneTextureAnimation.

    Field Type Default What it does
    columns integer 1 Frame-sheet columns. At least 1.
    rows integer 1 Frame-sheet rows. At least 1.
    frameCount integer 0 Frames played from firstFrame. 0 plays every cell from firstFrame on.
    framesPerSecond number 0 Playback rate. 0 holds the first frame of the run. Not negative.
    scrollU number 0 UV units per second along U.
    scrollV number 0 UV units per second along V, toward the bottom of the image.
    firstFrame integer 0 The cell the run starts at, counted from 0 in reading order. Within the sheet, and firstFrame + frameCount at most columns * rows.

    texture_clips

    A frame sheet with named clips cut out of it, one of which plays on the entity. texture_animation loops one run on the GPU's clock; these are stepped on the CPU by TextureClipSystem from the scene's clock, so a game can switch clip by name (TextureClips.play), see when a one-shot clip has finished, and a paused game holds still. The system gives the entity a TextureAnimation that holds the cell now showing, so an entity should not also carry a texture_animation. SceneTextureClips.

    Field Type Default What it does
    columns integer 1 Frame-sheet columns. At least 1.
    rows integer 1 Frame-sheet rows. At least 1.
    clips object of clips {} The sheet's runs by name; each is described below.
    clip string the first listed The clip that plays when the scene loads. One of clips.

    Each clip in clips is a SceneTextureClip:

    Field Type Default What it does
    firstFrame integer 0 The clip's first cell, counted from 0 in reading order from the top left.
    frameCount integer 1 Cells in the clip. At least 1, and firstFrame + frameCount at most columns * rows.
    framesPerSecond number 12 Playback rate. 0 holds the first cell.
    loop boolean true Whether the clip starts over when it ends. false holds its last cell.
